## Goal

To write a function that returns more than one value in a single call, and to unpack its result into names.

## Explanation

- A **tuple** is a struct without a name: ordered values, each with a name and a type, such as `(اصغر عدد64, اكبر عدد64)` (smallest, largest), with two fields or more (since 0.14.0).
- You write it as the function's return type, and return its value in parentheses: `ارجع (ص, ك)`.
- **Destructuring:** `ص, ك = حدود(درجات)` puts each field into a name, in order, and `_` is for a field you do not want.
- Or you keep the whole tuple under one name and read a field with a dot: `ح.اكبر`. `اطبع(ح)` prints the fields with their names.

## Common mistakes

The number of names in the destructuring does not match the number of fields in the tuple ([E0490](/en/docs/errors/catalog/#E0490)):

<Example file="lessons/صفوف_خطأ.م" title="Causes the error" />

The fix: one name for each field, and `_` for what you do not want (`ا, _ = نقطة()`). Note also that two tuples are not compared with `==` directly ([E0147](/en/docs/errors/catalog/#E0147)); compare their fields.
