**القاعدة.** لكل قيمة نوع يُعرف عند الترجمة. نوع المتغير يثبت من أول إسناد، أو يُكتب بعد اسمه: `س عدد64 = 3`. والأعداد
بأحجامها (منذ 0.12.0، `design-numerics.md` <small>(وثيقة في مستودع المجمّع)</small>): **التوسيع الآمن ضمني** (`عدد32` إلى `عدد64`،
`بايت` إلى `عدد32`، `كسر32` إلى `كسر64`)، و**التضييق صريح باسم النوع ويُفحص مداه** (`عدد8(ن)`)، و**الخلط بين نوعين لا
يسعهما نوع واحد خطأ ترجمة** (صحيح وكسر: `كسر64(س) / 2`). والحرفية تأخذ النوع المطلوب وتُفحص سعته عند الترجمة
(`semantics.md` <small>(وثيقة في مستودع المجمّع)</small>).

| النوع | القيمة | ملاحظات |
|---|---|---|
| `عدد64` (و`عدد8` `عدد16` `عدد32`) | صحيح بإشارة بحجمه | نوع الحرفية الصحيحة والأطوال والفهارس؛ التجاوز بعرض النوع خطأ تشغيل (يلتف في `--fast`، وبـ `جمع_ملتف` وأخواتها) |
| `طبيعي8` .. `طبيعي64`، و`بايت` (= `طبيعي8`) | صحيح بلا إشارة | `-` عليه خطأ ترجمة |
| `كسر64` (و`كسر32`) | عشري IEEE-754 بحجمه | نوع الحرفية الكسرية (`2.5`، `1e10`)؛ `1 / 2` صحيحة، `1 / 2.0` كسرية؛ والكسر إلى صحيح بتقريب مسمّى: `رياضيات.بتر/ارضيه/سقف/قرب` |
| `نص` | بايتات UTF-8 لا تتغير | الطول والفهرسة بنقاط الترميز؛ `+` بين نصين فقط؛ لا يكون `لاشيء` (منذ 0.11.0) |
| `رمز` | نقطة ترميز واحدة | `'م'`، وعنصر نص `ن[0]` |
| `منطقي` | `صواب` أو `خطاء` | |
| `لاشيء` | غياب القيمة | يُسند إلى النوع الاختياري `ن؟` وإلى `مؤشر[...]` و`مؤشر_خام` و`نص_سي` وحدها |
| `ن؟` | `ن` أو `لاشيء` (منذ 0.11.0) | `عدد؟`، `نص؟`، `قائمة[نص]؟`... يُفحص قبل استعماله `ن`: أدناه |
| `قائمة[ن]` | عناصر من نوع واحد، تكبر | **مرجعية**: `ب = ق` اسمان للقائمة نفسها |
| `قاموس[م, ق]` | مفاتيح `نص` أو عدد صحيح بحجمه أو `رمز` أو `منطقي` | مرجعي؛ المرور بترتيب الإدراج |
| `مصفوفة[ن, حجم]` | حجم ثابت | **بالقيمة**: تُنسخ عند الإسناد |
| هيكل | حقول مسمّاة ([الهياكل](/docs/language/structs/)) | بالقيمة |
| `مؤشر[ن]` و`مؤشر_خام` و`شريحة[ن]` | الطبقة المنخفضة ([الطبقة المنخفضة: خطر والشرائح والمؤشرات](/docs/language/low-level/)) | |
| `مخصص` | مخصص ذاكرة ([الذاكرة: المخصصات وخاتمه](/docs/memory/reference/)) | |
| `داله(أنواع) نوع` | مؤشر دالة ([الدوال](/docs/language/functions/)) | منذ 0.7.0 |

الاسمان `عدد` و`كسر` **أُزيلا** (منذ 0.12.0، `E0456`): يُكتب الحجم (`عدد64`، `كسر64` في الغالب). والأحجام كلها أنواع قيم
كاملة: متغير، ومعامل، وإرجاع، وحقل، وعنصر قائمة وقاموس ومصفوفة، ومفتاح قاموس (الصحيحة). وقراءة نص عدداً بـ
`حلل(ن, عدد64) والا 0`.

**النوع الاختياري** (منذ 0.11.0). `ن؟` قيمة من `ن` أو `لاشيء`، ولا تُستعمل كأنها `ن` قبل فحصها:
- `اذا س != لاشيء:` داخل الكتلة `س` من النوع `ن`؛ و`اذا س == لاشيء:` ثم `ارجع`/`توقف`/`تجاوز`/`خطا_قاتل` بعدها كذلك؛
  و`طالما س != لاشيء:` داخل الحلقة. التضييق لمتغير أو معامل، ويلغيه إسناد قيمة قد تكون لاشيء.
- `س والا بديل` قيمتها أو البديل؛ و`س والا:` ثم كتلة آخر سطر فيها البديل أو قفز.
- `اطبع(س)` تطبع القيمة أو `لاشيء`. وحقل `ن؟` في هيكل بلا قيمة يبدأ `لاشيء`.
- ما يرجع غياباً في المكتبة: `بحث` (`عدد؟`)، و`اقرأ()` (`نص؟`: لاشيء عند نهاية الإدخال)، و`نظام.بيئة` و`من_نص_سي` (`نص؟`).
- الهيكل والصف يكونان اختياريين منذ 0.14.0 (`نقطة؟`)؛ والمصفوفة والشريحة لا. والمؤشرات تقبل `لاشيء` بلا `؟` (كمؤشرات C).

**الهيكل الاختياري** (منذ 0.14.0): دالة ترجع هيكلاً أو لاشيء، والفحص كبقية `ن؟`.

<HBExample id="language/02-types.md#3" />

**الصف والإرجاع المتعدد** (منذ 0.14.0، `design-types-survey.md` <small>(وثيقة في مستودع المجمّع)</small> القسم 3). الصف هيكل بلا اسم بأسماء حقوله وأنواعها: `(خارج عدد64, باقي عدد64)`، حقلان فأكثر. يُكتب نوعاً حيث يُكتب نوع (إرجاع، ومتغير `ز (س عدد64, ص عدد64) = (3, 4)`، ومعامل، وعنصر قائمة وقاموس)، وقيمته `(ا, ب)` تأخذ نوعها من موضعها. ويُفكّ `خ, ب = ف()` (و`_` لحقل لا تريده)، وفي `لكل (س, ص) في ...`، ويُقرأ حقله `ن.خارج`، ويُطبع `(خارج: 3, باقي: 1)`. صفّان بالأسماء والأنواع نفسها بالترتيب نفسه نوع واحد. ومع `!ن`: `داله ف() !(ا عدد64, ب عدد64)` و`خ, ب = جرّب ف()` و`ف() والا (0, 0)`.

**النوع الجديد القوي نمطاً** (بلا ميزة جديدة): هيكل بحقل واحد يجعل المتر والثانية نوعين لا يختلطان، والشيفرة المولَّدة له هي شيفرة `كسر64` نفسها (`design-types-survey.md` <small>(وثيقة في مستودع المجمّع)</small>، التجربة 7).

**النص بالبايت** (منذ 0.14.0): `طول` و`جزء` و`بحث` و`ن[ف]` بالحرف للنص قيمةً؛ و`طول_بايت` و`بايت_عند` و`جزء_بايت` (عرض، والحدّ على حدّ حرف UTF-8) و`بحث_بايت` بالبايت للنص بيانات، و`بايتات_نص` و`نص_من_بايتات` بين النص و`شريحة[بايت]`. والأعداد تُكتب سداسيةً `0xFF` وثنائيةً `0b1010` أيضاً.

<HBExample id="language/02-types.md#7" />

**القيود المعروفة.** لا أنواع معمَّمة يكتبها المستخدم (`قائمة` بلا نوع عناصر في معامل تُنسخ الدالة لكل نوع، القسم
[الدوال](/docs/language/functions/)). لا أنواع جمع تحمل أعضاؤها حمولة (التعداد بحمولة في `design-generics.md` <small>(وثيقة في مستودع المجمّع)</small>)؛ والتعداد (أعضاء بلا قيم) في
[التعداد](/docs/language/enums/).
مقارنة عدد بكسر فوق 2^53 تقريبية. وفهرسة النص بالحرف (`ن[ف]`) كلفتها خطية في طوله: النص UTF-8، والوصول إلى الحرف رقم ف
يعدّ من أوله؛ للمرور على النص كله `لكل ح في ن` (`strings-and-print.md` <small>(وثيقة في مستودع المجمّع)</small>).
