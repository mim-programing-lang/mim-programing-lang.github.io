قرار المالك (2026-10-18): الخيار أ من `errors-design.md` <small>(وثيقة في مستودع المجمّع)</small>. **كسر بلا طبقة توافق**: برنامج كان
يستدعي دالة صارت `!نوع` لا يُترجم حتى يعالج فشلها. ورسالة الترجمة تقول ما يُكتب.

## ما تغيّر

| كان | صار | الإصلاح الأقصر |
|---|---|---|
| `ن = ملفات.اقرأ_ملف(م)` يوقف البرنامج إن فشل | `!نص` | `ن = جرّب ملفات.اقرأ_ملف(م)` (في دالة `!نوع`، أو المستوى الأعلى) |
| `ملفات.اكتب_ملف(م, ن)` جملة | `!فراغ` | `جرّب ملفات.اكتب_ملف(م, ن)` |
| `الحق_بملف`، `اقرأ_سطور`، `سرد_مجلد`، `انشئ_مجلد`، `احذف_ملف` | `!نوع` | كما سبق |
| `عدد("12")` و`كسر("2.5")` | `!عدد` و`!كسر` | `عدد(ن) والا 0`، أو `جرّب عدد(ن)` |
| `ش = حاول_احجز(...)` ثم `ش == لاشيء` | `!شريحة` | `ش = حاول_احجز(...) والا خ:` ثم ما يُفعل |
| `جرب` و`والا` و`خاتمه_عند_خطأ` أسماء عادية | كلمات محجوزة | غيّر الاسم |
| رسالة «لا يمكن تحويل النص 'س' إلى عدد» برمز 3 | لا تحدث إلا بـ`جرّب` في المستوى الأعلى: «خطأ لم يُعالَج: صيغة_خاطئة» برمز 3 | عالج الخطأ |

## مثال قبل وبعد

قبل (0.6):

```ميم nocheck
استورد ملفات
ن = ملفات.اقرأ_ملف("ارقام.txt")
مج = 0
لكل سطر في تقسيم(ن, "\n"):
    مج += عدد(سطر)
اطبع(مج)
```

## ما لم يتغير

الفهرس خارج الحدود، والقسمة على صفر، والتجاوز، والمفتاح الغائب من القاموس، و`عدد(كسر)` خارج المدى، ونفاد الذاكرة في كل حجز
إلا `حاول_احجز`: أخطاء تشغيل كما كانت (أخطاء برمجة لا حالات متوقعة).
