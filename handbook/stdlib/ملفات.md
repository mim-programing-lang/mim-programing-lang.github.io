# الوحدة `ملفات`

**مولَّدة** من تعليقات الشرح في `stdlib/ملفات.م` (`meem --list-module ملفات --json`). تُستورد بـ`استورد ملفات`
وتُستدعى دوالها `ملفات.دالة(...)`. الشرح الأطول وأمثلته في [../../stdlib.md](../../stdlib.md).

## `اقرأ_ملف`

**التوقيع:** `اقرأ_ملف(مسار نص, م مخصص)` ← `!نص`

محتوى الملف كله نصاً. يفشل بـ: غير_موجود، ممنوع، ليس_ملفا (مجلد)، كبير_جدا (أكبر من 1 غ.ب)، ليس_نصا (بايتات
ليست UTF-8، أو بايت صفري)، لا_ذاكرة، فشل_النظام. نهايات الأسطر تبقى كما هي في الملف.
النص من المخصص م إن مُرّر، وإلا من الافتراضي؛ يملكه المستدعي ويحرره بـ حرر(النص[, م]).
استعمال: نص_الملف = جرّب اقرأ_ملف("بيانات.txt")   أو   اقرأ_ملف("بيانات.txt") والا ""

المخصص الأخير اختياري: إن تُرك فالافتراضي.

```ميم
استورد ملفات
جرّب ملفات.اكتب_ملف("ملاحظة.txt", "سطر اول\nسطر ثان\n")
ن = جرّب ملفات.اقرأ_ملف("ملاحظة.txt")
اطبع(طول(ن), " حرفاً")
غائب = ملفات.اقرأ_ملف("غائب.txt") والا خ:
    اطبع("تعذّرت القراءة: ", خ)
    ""
```

```الناتج
16 حرفاً
تعذّرت القراءة: غير_موجود: غائب.txt (رقم النظام 2: لا ملف ولا مجلد بهذا الاسم)
```

## `اكتب_ملف`

**التوقيع:** `اكتب_ملف(مسار نص, محتوى نص)` ← `!فراغ`

يكتب النص في الملف: ينشئه إن لم يوجد، ويستبدل محتواه كله إن وُجد. يفشل بـ: غير_موجود (مجلد ناقص في المسار)،
ممنوع، ليس_ملفا، فشل_النظام. لا يضيف سطراً جديداً في الآخر.
استعمال: جرّب اكتب_ملف("ناتج.txt", "السطر الأول\n")

```ميم
استورد ملفات
جرّب ملفات.اكتب_ملف("ناتج.txt", "مرحبا\n")
جرّب ملفات.اكتب_ملف("ناتج.txt", "بديل")
اطبع(جرّب ملفات.اقرأ_ملف("ناتج.txt"))
ملفات.اكتب_ملف("لا_مجلد/ناتج.txt", "س") والا خ:
    اطبع("تعذّرت الكتابة: ", خ)
```

```الناتج
بديل
تعذّرت الكتابة: غير_موجود: لا_مجلد/ناتج.txt (رقم النظام 2: لا ملف ولا مجلد بهذا الاسم)
```

## `الحق_بملف`

**التوقيع:** `الحق_بملف(مسار نص, محتوى نص)` ← `!فراغ`

يلحق النص بآخر الملف، وينشئه إن لم يوجد. أخطاؤه كـ اكتب_ملف.
استعمال: جرّب الحق_بملف("سجل.txt", "حدث جديد\n")

```ميم
استورد ملفات
جرّب ملفات.الحق_بملف("سجل.txt", "حدث اول\n")
جرّب ملفات.الحق_بملف("سجل.txt", "حدث ثان\n")
اطبع(جرّب ملفات.اقرأ_ملف("سجل.txt"))
```

```الناتج
حدث اول
حدث ثان

```

## `يوجد_ملف`

**التوقيع:** `يوجد_ملف(مسار نص)` ← `منطقي`

هل في المسار ملف يُفتح للقراءة؟ خطاء لما لا وجود له، وللمجلد، ولما لا صلاحية لقراءته. لا تفشل.

```ميم
استورد ملفات
اطبع(ملفات.يوجد_ملف("/مسار/لا/وجود/له"))
```

```الناتج
خطاء
```

```ميم
استورد ملفات
جرّب ملفات.اكتب_ملف("هنا.txt", "")
اطبع(ملفات.يوجد_ملف("هنا.txt"), " ", ملفات.يوجد_ملف("غائب.txt"), " ", ملفات.يوجد_ملف("."))
```

```الناتج
صواب خطاء خطاء
```

## `اقرأ_سطور`

**التوقيع:** `اقرأ_سطور(مسار نص, م مخصص)` ← `!قائمة[نص]`

سطور الملف: محتواه مقسوماً عند كل \n، بلا علامة النهاية نفسها. سطر أخير بلا نهاية سطر يُعدّ سطراً؛ والملف
الفارغ قائمة فارغة. نهاية السطر \r\n (ويندوز) تُزال كلها: لا يبقى \r في آخر سطر (منذ 0.8.0).
أخطاؤه كـ اقرأ_ملف. القائمة ونصوصها من المخصص م إن مُرّر، وإلا من الافتراضي.
استعمال: لكل سطر في جرّب اقرأ_سطور("بيانات.txt"):

المخصص الأخير اختياري: إن تُرك فالافتراضي.

```ميم
استورد ملفات
جرّب ملفات.اكتب_ملف("قائمة.txt", "خبز\nحليب\nتمر")
لكل سطر في جرّب ملفات.اقرأ_سطور("قائمة.txt"):
    اطبع("- ", سطر)
```

```الناتج
- خبز
- حليب
- تمر
```

## `سرد_مجلد`

**التوقيع:** `سرد_مجلد(مسار نص, م مخصص)` ← `!قائمة[نص]`

أسماء ما في المجلد (ملفات ومجلدات) مرتّبة بترتيب نقاط الترميز، بلا "." و"..". يفشل بـ: غير_موجود، ممنوع،
ليس_مجلدا، فشل_النظام. القائمة ونصوصها من المخصص م إن مُرّر، وإلا من الافتراضي.
استعمال: لكل اسم في جرّب سرد_مجلد("."):

المخصص الأخير اختياري: إن تُرك فالافتراضي.

```ميم
استورد ملفات
جرّب ملفات.انشئ_مجلد("صور")
جرّب ملفات.اكتب_ملف("صور/ب.png", "")
جرّب ملفات.اكتب_ملف("صور/ا.png", "")
اطبع(جرّب ملفات.سرد_مجلد("صور"))
س = ملفات.سرد_مجلد("صور/ا.png") والا خ:
    اطبع("ليس مجلداً: ", خ)
    [""]
```

```الناتج
[ا.png, ب.png]
ليس مجلداً: ليس_مجلدا: صور/ا.png (رقم النظام 20: ليس مجلداً)
```

## `انشئ_مجلد`

**التوقيع:** `انشئ_مجلد(مسار نص)` ← `!فراغ`

ينشئ مجلداً (لا ينشئ ما فوقه). يفشل بـ: موجود، غير_موجود (ما فوقه)، ممنوع، ليس_مجلدا، فشل_النظام.
استعمال: جرّب انشئ_مجلد("ناتج")

```ميم
استورد ملفات
جرّب ملفات.انشئ_مجلد("ناتج")
ملفات.انشئ_مجلد("ناتج") والا خ:
    اطبع("مرة ثانية: ", خ)
ملفات.انشئ_مجلد("لا/فرعي") والا خ:
    اطبع("بلا الأب: ", خ)
```

```الناتج
مرة ثانية: موجود: ناتج (رقم النظام 17: موجود من قبل)
بلا الأب: غير_موجود: لا/فرعي (رقم النظام 2: لا ملف ولا مجلد بهذا الاسم)
```

## `احذف_ملف`

**التوقيع:** `احذف_ملف(مسار نص)` ← `!فراغ`

يحذف ملفاً (لا مجلداً). يفشل بـ: غير_موجود، ممنوع، ليس_ملفا (مجلد)، فشل_النظام.
استعمال: جرّب احذف_ملف("مؤقت.txt")

```ميم
استورد ملفات
جرّب ملفات.اكتب_ملف("مؤقت.txt", "س")
جرّب ملفات.احذف_ملف("مؤقت.txt")
اطبع(ملفات.يوجد_ملف("مؤقت.txt"))
ملفات.احذف_ملف("مؤقت.txt") والا خ:
    اطبع("مرة ثانية: ", خ)
```

```الناتج
خطاء
مرة ثانية: غير_موجود: مؤقت.txt (رقم النظام 2: لا ملف ولا مجلد بهذا الاسم)
```

## `افتح_للقراءة`

**التوقيع:** `افتح_للقراءة(مسار نص)` ← `!قارئ`

يفتح الملف للقراءة سطراً سطراً أو بايتات. يفشل بـ: غير_موجود، ممنوع، فشل_النظام (والمسار في الخطأ).
استعمال: ق = جرّب ملفات.افتح_للقراءة("بيانات.csv")  ثم  خاتمه ملفات.اغلق(ق)

## `افتح_للكتابة`

**التوقيع:** `افتح_للكتابة(مسار نص)` ← `!كاتب`

يفتح الملف للكتابة: ينشئه، أو يفرّغه إن وُجد. يفشل بـ: غير_موجود (مجلد ناقص)، ممنوع، ليس_ملفا، فشل_النظام.
استعمال: ك = جرّب ملفات.افتح_للكتابة("ناتج.txt")  ثم  خاتمه جرّب ملفات.اغلق(ك)

## `افتح_للالحاق`

**التوقيع:** `افتح_للالحاق(مسار نص)` ← `!كاتب`

يفتح الملف للإلحاق بآخره، وينشئه إن لم يوجد. أخطاؤه كـ افتح_للكتابة.
استعمال: سجل = جرّب ملفات.افتح_للالحاق("خادم.log")  ثم  خاتمه جرّب ملفات.اغلق(سجل)

## `الدخل`

**التوقيع:** `الدخل()` ← `قارئ`

الدخل القياسي قارئاً، والخرج والخطأ القياسيان كاتبين. اغلق لا يغلقها، والخرج يشارك مخزن اطبع فلا يختلط ترتيبهما.
استعمال: سطر = جرّب ملفات.اقرأ_سطر(ملفات.الدخل())

## `الخرج`

**التوقيع:** `الخرج()` ← `كاتب`

الخرج القياسي كاتباً (مخزن اطبع نفسه).
استعمال: جرّب ملفات.اكتب_سطر(ملفات.الخرج(), "تم")

## `الخطأ`

**التوقيع:** `الخطأ()` ← `كاتب`

مجرى الأخطاء القياسي كاتباً.
استعمال: جرّب ملفات.اكتب_سطر(ملفات.الخطأ(), "تحذير: ", رسالة_)

## `اقرأ_سطر`

**التوقيع:** `اقرأ_سطر(ق قارئ, م مخصص)` ← `!نص؟`

السطر التالي بلا \n ولا \r\n، أو لاشيء عند نهاية الملف؛ والسطر الأخير بلا نهاية سطر سطر عادي. يفشل بـ: ليس_نصا
(بايتات ليست UTF-8، أو بايت صفري)، كبير_جدا (أطول من 1 غ.ب)، فشل_النظام. النص من المخصص م، أو الافتراضي.
استعمال:  سطر = جرّب ملفات.اقرأ_سطر(ق)  ثم  اذا سطر == لاشيء: توقف

المخصص الأخير اختياري: إن تُرك فالافتراضي.

## `اغلق`

**التوقيع:** `اغلق(ق قارئ)` ← `فراغ`

يغلق الملف. للقارئ لا يفشل؛ وللكاتب يفرّغ ما بقي في مخزنه أولاً فقد يفشل (!فراغ): اكتب  خاتمه جرّب ملفات.اغلق(ك).
الإغلاق مرتين، والاستعمال بعد الإغلاق بأي اسم، خطأ تشغيل. والدخل والخرج والخطأ القياسية لا تُغلق (الكاتب يُفرَّغ).
استعمال: خاتمه ملفات.اغلق(ق)   أو للكاتب   خاتمه جرّب ملفات.اغلق(ك)

## `اكتب`

**التوقيع:** `اكتب(ك كاتب, نص_ نص)` ← `!فراغ`

يكتب القيم في الملف كما تُدمج بـ دمج_نصوص (نصوص، وأعداد، ورموز، وقيم منطقية، وأعضاء تعداد)، بلا فاصل بينها.
اكتب_سطر يضيف \n في آخرها. يفشل بـ: ممنوع، فشل_النظام (القرص ممتلئ مثلاً، وقد يظهر عند التفريغ أو الإغلاق).
استعمال: جرّب ملفات.اكتب(ك, اسم, ",", عدد_, "\n")   أو   جرّب ملفات.اكتب_سطر(ك, "مجموع: ", م)

## `اكتب_سطر`

**التوقيع:** `اكتب_سطر(ك كاتب, نص_ نص)` ← `!فراغ`

اكتب ثم \n في آخر القيم.
استعمال: جرّب ملفات.اكتب_سطر(ك, "مجموع: ", م)

## `فرّغ`

**التوقيع:** `فرّغ(ك كاتب)` ← `!فراغ`

يفرّغ مخزن الكاتب إلى الملف الآن (لا يضيع ما كُتب إن قُتل البرنامج بعدها). يفشل بـ: فشل_النظام.
استعمال: جرّب ملفات.فرّغ(سجل)

## `اقرأ_بايتات`

**التوقيع:** `اقرأ_بايتات(ق قارئ, ش شريحة[بايت])` ← `!عدد64`

يملأ الشريحة من الملف حتى طولها، ويرجع عدد ما قُرئ؛ 0 عند نهاية الملف. يفشل بـ: فشل_النظام.
استعمال: كتلة = احجز(بايت, 65536)  ثم  ن = جرّب ملفات.اقرأ_بايتات(ق, كتلة)

## `اكتب_بايتات`

**التوقيع:** `اكتب_بايتات(ك كاتب, ش شريحة[بايت])` ← `!فراغ`

يكتب الشريحة كلها (والجزء منها بـ قطعة). يفشل بـ: ممنوع، فشل_النظام.
استعمال: جرّب ملفات.اكتب_بايتات(ك, قطعة(كتلة, 0, ن))

## `انتقل`

**التوقيع:** `انتقل(ق قارئ, موضع عدد64)` ← `!فراغ`

ينقل موضع القراءة إلى البايت رقم موضع من أول الملف، و الموضع(ق) موضعها الآن. يفشلان بـ: فشل_النظام.
استعمال: جرّب ملفات.انتقل(ق, 8)

## `الموضع`

**التوقيع:** `الموضع(ق قارئ)` ← `!عدد64`

موضع القراءة الآن بالبايت من أول الملف.
استعمال: م = جرّب ملفات.الموضع(ق)

## `اقرأ_ملف_بايتات`

**التوقيع:** `اقرأ_ملف_بايتات(مسار نص, م مخصص)` ← `!شريحة[بايت]`

الملف كله بايتات، بلا فحص UTF-8 (للصور والملفات الثنائية). يفشل كـ اقرأ_ملف إلا ليس_نصا. الشريحة من المخصص م،
أو الافتراضي، ويحررها المستدعي بـ حرر(ش[, م]).
استعمال: ب = جرّب ملفات.اقرأ_ملف_بايتات("صورة.png")  ثم  خاتمه حرر(ب)

المخصص الأخير اختياري: إن تُرك فالافتراضي.

## `اكتب_ملف_بايتات`

**التوقيع:** `اكتب_ملف_بايتات(مسار نص, ش شريحة[بايت])` ← `!فراغ`

يكتب الشريحة في الملف: ينشئه أو يستبدل محتواه. أخطاؤه كـ اكتب_ملف.
استعمال: جرّب ملفات.اكتب_ملف_بايتات("ناتج.bin", ش)

## `قارئ` (هيكل)

`_صندوق مؤشر[_صندوق_ملف]`

ملف مفتوح للقراءة (من افتح_للقراءة أو الدخل()). يُغلق بـ اغلق(ق)، والأحسن  خاتمه ملفات.اغلق(ق)  بعد فتحه.
استعمال: ق قارئ = جرّب ملفات.افتح_للقراءة("بيانات.txt")

## `كاتب` (هيكل)

`_صندوق مؤشر[_صندوق_ملف]`

ملف مفتوح للكتابة (من افتح_للكتابة أو افتح_للالحاق أو الخرج() أو الخطأ()). اغلق(ك) يفرّغ ما بقي وقد يفشل.
استعمال: ك كاتب = جرّب ملفات.افتح_للكتابة("ناتج.txt")
