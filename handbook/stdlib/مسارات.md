# الوحدة `مسارات`

**مولَّدة** من تعليقات الشرح في `stdlib/مسارات.م` (`meem --list-module مسارات --json`). تُستورد بـ`استورد مسارات`
وتُستدعى دوالها `مسارات.دالة(...)`. الشرح الأطول وأمثلته في [../../stdlib.md](../../stdlib.md).

## `ضم`

**التوقيع:** `ضم(اول نص, ثان نص, م مخصص)` ← `نص`

المساران مضمومين بفاصل واحد: «/» بينهما إلا إن انتهى الأول به. والثاني المطلق (يبدأ بـ «/») يُرجَع وحده، والأول
الفارغ يُرجع الثاني. النص من المخصص م إن مُرّر، وإلا من الافتراضي.

المخصص الأخير اختياري: إن تُرك فالافتراضي.

```ميم
استورد مسارات
اطبع(مسارات.ضم("بيانات", "سجل.txt"))
```

```الناتج
بيانات/سجل.txt
```

```ميم
استورد مسارات
اطبع(مسارات.ضم("بيانات/", "سجل.txt"))
```

```الناتج
بيانات/سجل.txt
```

```ميم
استورد مسارات
اطبع(مسارات.ضم("بيانات", "/tmp/ا"))
```

```الناتج
/tmp/ا
```

## `اسم_الملف`

**التوقيع:** `اسم_الملف(مسار نص)` ← `نص؟`

الجزء الأخير من المسار بعد آخر «/»: المسار كله إن لم يكن فيه فاصل، ولاشيء إن انتهى بفاصل (منذ 0.12.0؛ كان نصاً
فارغاً).

```ميم
استورد مسارات
اطبع(مسارات.اسم_الملف("بيانات/2026/سجل.txt") والا "")
```

```الناتج
سجل.txt
```

```ميم
استورد مسارات
اطبع(مسارات.اسم_الملف("سجل.txt") والا "")
```

```الناتج
سجل.txt
```

```ميم
استورد مسارات
اطبع(مسارات.اسم_الملف("بيانات/") == لاشيء)
```

```الناتج
صواب
```

## `المجلد`

**التوقيع:** `المجلد(مسار نص)` ← `نص؟`

المجلد: ما قبل آخر «/»، ولاشيء إن لم يكن فيه فاصل (منذ 0.12.0؛ كان نصاً فارغاً)، و«/» لمسار في الجذر.

```ميم
استورد مسارات
اطبع(مسارات.المجلد("بيانات/2026/سجل.txt") والا "")
```

```الناتج
بيانات/2026
```

```ميم
استورد مسارات
اطبع(مسارات.المجلد("/سجل.txt") والا "")
```

```الناتج
/
```

```ميم
استورد مسارات
اطبع(مسارات.المجلد("سجل.txt") == لاشيء)
```

```الناتج
صواب
```

## `الامتداد`

**التوقيع:** `الامتداد(مسار نص)` ← `نص؟`

امتداد اسم الملف بنقطته: من آخر «.» في الجزء الأخير، ولاشيء إن لم يكن فيه نقطة أو كانت النقطة أول حرف فيه
(ملف مخفي مثل .bashrc) أو انتهى المسار بفاصل (منذ 0.12.0؛ كان نصاً فارغاً).

```ميم
استورد مسارات
اطبع(مسارات.الامتداد("صور/رحلة.png") والا "")
```

```الناتج
.png
```

```ميم
استورد مسارات
اطبع(مسارات.الامتداد("نسخة.tar.gz") والا "")
```

```الناتج
.gz
```

```ميم
استورد مسارات
اطبع(مسارات.الامتداد(".bashrc") == لاشيء)
```

```الناتج
صواب
```
