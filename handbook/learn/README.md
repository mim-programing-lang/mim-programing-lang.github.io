# منهج مقترح للمبتدئ

**مادة خام للموقع، لا صفحات نهائية.** لكل درس: هدفه، وبرنامج مثال بمخرجه (يُشغَّل في `tests/test_docs.py`)، والأخطاء
الشائعة فيه (مشروحة مع إصلاحها في [../errors/common.md](../errors/common.md))، والمرجع. الترتيب مقترح: كل درس
يستعمل ما قبله وحده. الأمثلة تُشغَّل بإدخال فارغ، فـ`اقرأ` ترجع نصاً فارغاً.

| 4. الشروط | يختار بين طريقين بـ`اذا` و`غير ذلك` |
| 5. الحلقات | يكرر بـ`لكل` و`مدى` و`طالما`، ويوقف بـ`توقف` |
| 6. القوائم | يضيف ويرتب ويبحث في قائمة |
| 7. القواميس | يربط مفتاحاً بقيمة ويمر على المفاتيح بترتيب إدراجها |

## 1. الطباعة والنصوص

**الهدف:** يطبع نصاً وأعداداً، ويعرف أن `اطبع` تأخذ قيماً كثيرة.

```ميم
اطبع("مرحبا بالعالم")
اطبع("عمري ", 12, " سنة")
```

```الناتج
مرحبا بالعالم
عمري 12 سنة
```


**أخطاء شائعة:** نص بلا علامتي تنصيص؛ `+` بين نص وعدد.

**المرجع:** [03-expressions.md](../language/03-expressions.md)

## 2. المتغيرات والحساب

**الهدف:** يحفظ قيمة باسم ويحسب بها؛ يفرّق بين القسمة الصحيحة والكسرية.

```ميم
الطول = 7
العرض = 2
اطبع(الطول * العرض, " ", الطول / العرض, " ", الطول / 2.0)
```

```الناتج
14 3 3.5
```



**أخطاء شائعة:** تغيير نوع المتغير بعد أول إسناد؛ وتسمية متغير باسم مدمجة محجوزة (`طول = 7` خطأ نحوي: «متوقع '('»).

**المرجع:** [02-types.md](../language/02-types.md)

## 3. الإدخال

**الهدف:** يقرأ سطراً من المستخدم ويحوّله عدداً.

```ميم
اسم = اقرأ("ما اسمك؟ ")
اطبع("أهلاً ", اسم)
```

```الناتج
ما اسمك؟ أهلاً 
```


**أخطاء شائعة:** `عدد(اقرأ())` من النوع `!عدد`: النص قد لا يكون عدداً، فيُكتب `عدد(اقرأ()) والا 0`.

**المرجع:** [builtins.md](../stdlib/builtins.md)

## 4. الشروط

**الهدف:** يختار بين طريقين بـ`اذا` و`غير ذلك`.

```ميم
درجة = 75
اذا درجة >= 90:
    اطبع("ممتاز")
غير ذلك اذا درجة >= 60:
    اطبع("ناجح")
غير ذلك:
    اطبع("راسب")
```

```الناتج
ناجح
```


**أخطاء شائعة:** نسيان `:`، أو مسافة بادئة غير متساوية.

**المرجع:** [04-statements.md](../language/04-statements.md)

## 5. الحلقات

**الهدف:** يكرر بـ`لكل` و`مدى` و`طالما`، ويوقف بـ`توقف`.

```ميم
مج = 0
لكل ع في مدى(1, 11):
    مج += ع
اطبع(مج)
ن = 1
طالما ن < 100:
    ن *= 2
اطبع(ن)
```

```الناتج
55
128
```


**أخطاء شائعة:** `مدى(1, 10)` لا تشمل 10.

**المرجع:** [04-statements.md](../language/04-statements.md)

## 6. القوائم

**الهدف:** يضيف ويرتب ويبحث في قائمة.

```ميم
درجات = [70, 95, 82]
اضف(درجات, 60)
رتب(درجات)
اطبع(درجات, " ", طول(درجات), " ", بحث(درجات, 95))
```

```الناتج
[60, 70, 82, 95] 4 3
```


**أخطاء شائعة:** فهرس خارج القائمة؛ والقائمة مرجعية (`ب = ق` لا تنسخ).

**المرجع:** [builtins.md](../stdlib/builtins.md)

## 7. القواميس

**الهدف:** يربط مفتاحاً بقيمة ويمر على المفاتيح بترتيب إدراجها.

```ميم
اعمار = {"سارة": 30, "علي": 25}
اعمار["منى"] = 28
لكل اسم في اعمار:
    اطبع(اسم, ": ", اعمار[اسم])
اطبع(مفاتيح(اعمار))
```

```الناتج
سارة: 30
علي: 25
منى: 28
[سارة, علي, منى]
```


**أخطاء شائعة:** قراءة مفتاح غائب (افحص بـ`يحوي`).

**المرجع:** [builtins.md](../stdlib/builtins.md)

## 8. الدوال

**الهدف:** يكتب دالة بمعاملات ونوع إرجاع، ويستدعيها بعد تعريفها.

```ميم
داله مساحة(ط كسر, ع كسر) كسر:
    ارجع ط * ع
اطبع(مساحة(2.5, 4.0))
```

```الناتج
10.0
```


**أخطاء شائعة:** استدعاء قبل التعريف؛ مسار بلا `ارجع`.

**المرجع:** [05-functions.md](../language/05-functions.md)

## 9. الهياكل

**الهدف:** يجمع بيانات شيء واحد في هيكل.

```ميم
هيكل طالب:
    اسم نص
    درجة عدد
ط = طالب("ليلى", 91)
اطبع(ط.اسم, " ", ط.درجة)
اطبع(ط)
```

```الناتج
ليلى 91
طالب { اسم: ليلى, درجة: 91 }
```


**أخطاء شائعة:** عدد القيم لا يطابق عدد الحقول.

**المرجع:** [06-structs.md](../language/06-structs.md)

## 10. النصوص أعمق

**الهدف:** يقسم ويبحث ويقص الفراغات.

```ميم
سطر = "  تفاح، موز، عنب  "
قطع = تقسيم(قص_الفراغات(سطر), "، ")
اطبع(قطع, " ", يحوي(سطر, "موز"), " ", يبدأ_بـ(قطع[0], "تف"))
```

```الناتج
[تفاح, موز, عنب] صواب صواب
```


**أخطاء شائعة:** الطول بنقاط الترميز لا بالبايتات، والتشكيل يُعدّ.

**المرجع:** [builtins.md](../stdlib/builtins.md)

## 11. الوحدات

**الهدف:** يستورد وحدة قياسية ويستعمل دوالها.

```ميم
استورد رياضيات
اطبع(رياضيات.جذر(81.0), " ", رياضيات.نسق(رياضيات.باي, 2))
```

```الناتج
9.0 3.14
```


**أخطاء شائعة:** اسم وحدة غير موجود.

**المرجع:** [07-modules.md](../language/07-modules.md)

## 12. الملفات

**الهدف:** يكتب ملفاً ويقرأ سطوره.

```ميم
استورد ملفات
جرّب ملفات.اكتب_ملف("قائمة.txt", "خبز\nحليب\n")
لكل غرض في جرّب ملفات.اقرأ_سطور("قائمة.txt"):
    اطبع("- ", غرض)
```

```الناتج
- خبز
- حليب
```



**أخطاء شائعة:** نسيان `جرّب` أو `والا` مع دالة قد تفشل (خطأ ترجمة يقول ما يُكتب)؛ و`جرّب` في المستوى الأعلى تنهي البرنامج برمز 3 إن فشلت.

**المرجع:** [ملفات.md](../stdlib/ملفات.md)

## 13. الذاكرة للمبتدئ

**الهدف:** يعرف أن ما يُبنى يعود عند الخروج، و`خاتمه حرر` في الحلقات الطويلة.

```ميم
لكل ع في مدى(0, 3):
    ن = "سطر " + نص(ع)
    خاتمه حرر(ن)
    اطبع(ن)
```

```الناتج
سطر 0
سطر 1
سطر 2
```


**أخطاء شائعة:** نسيان التحرير في حلقة طويلة يرفع ذروة الذاكرة (يكشفها `--debug-mem`).

**المرجع:** [08-memory.md](../language/08-memory.md)
