# العبارات

**القاعدة.** عبارة في كل سطر. الكتلة تبدأ بعد `:` بمسافة بادئة. **النطاق نطاق دالة**: `اذا` و`طالما` و`لكل` لا تنشئ
نطاقاً ([../../semantics.md](../../semantics.md)).

| العبارة | الصيغة |
|---|---|
| إسناد | `س = قيمة`، وبنوع `س عدد = قيمة`، ومركّب `+=` `-=` `*=` `/=` `%=` |
| ثابت | `ثابت حد = 10` (لا يُسند إليه بعد) |
| شرط | `اذا ...:` ثم `غير ذلك اذا ...:` ثم `غير ذلك:` |
| حلقة شرطية | `طالما ...:` |
| حلقة على عناصر | `لكل ع في مدى(من, الى)` أو قائمة أو مصفوفة أو نص (رموزه) أو قاموس (مفاتيحه) أو شريحة |
| الخروج والتخطي | `توقف`، `تجاوز` |
| مطابقة | `حالات قيمة:` ثم `حاله ا:` أو `حاله ا او ب:` أو `حاله _:` |
| تأجيل | `خاتمه جملة`: تُنفَّذ عند الخروج من الكتلة، بعكس الترتيب |
| متغير عام في دالة | `عام س` قبل الإسناد إليه |

```ميم
مج = 0
لكل ع في مدى(1, 6):
    اذا ع == 3:
        تجاوز
    مج += ع
حالات مج:
    حاله 0:
        اطبع("صفر")
    حاله 12 او 13:
        اطبع("مج = ", مج)
    حاله _:
        اطبع("غير ذلك")
لكل مفتاح في {"ب": 2, "ا": 1}:
    اطبع(مفتاح)
داله عدّ() فراغ:
    خاتمه اطبع("ثانياً")
    اطبع("أولاً")
عدّ()
```

```الناتج
مج = 12
ب
ا
أولاً
ثانياً
```


**القيود المعروفة.** `مدى(النهاية)` و`مدى(البداية, النهاية)` و`مدى(البداية, النهاية, الخطوة)` لا تشمل النهاية، وهي
لـ`لكل` وحدها. لا `لكل` بفهرس وعنصر معاً.

**أخطاء محتملة.**

```ميم
اذا صواب
    اطبع(1)
```
