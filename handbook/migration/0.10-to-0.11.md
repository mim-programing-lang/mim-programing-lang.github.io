# الترحيل من 0.10 إلى 0.11

المصدر: [../../../CHANGELOG.md](../../../CHANGELOG.md) (قسم 0.11.0)، والتصميم [../../design-0.11.md](../../design-0.11.md).
**قبل 1.0 أفضل تصميم يفوز على التوافق** ([../../deprecation-policy.md](../../deprecation-policy.md)): ما يكسر هنا يكسر بلا
طبقة توافق، و**لا يكتب `--fix` شيئاً منه**. كل رسالة جديدة تقول في تلميحها ما يُكتب.

الكسر الأكبر: **`نص` لا يكون `لاشيء`**. الغياب نوع اختياري (`نص؟`، `عدد؟`...) يُفحص قبل الاستعمال، والمكتبة كلها بتواقيعها
النهائية: ما كان يرجع قيمة حارسة (`-1`، أو `لاشيء` في نص) يرجع نوعاً اختيارياً.

## ما يتغير

| كان في 0.10 | صار في 0.11.0 | ما تفعله |
|---|---|---|
| `س نص = لاشيء`، و`نص` قد يحمل `لاشيء` | `E0252` وتلميحه «اكتب النوع الاختياري 'نص؟'» | `س نص؟ = لاشيء`، ثم `اذا س != لاشيء:` قبل استعماله، أو `س والا "بديل"` |
| `س = لاشيء` بلا نوع | `E0436` | اكتب النوع: `س نص؟ = لاشيء` |
| مقارنة قيمة لا تكون `لاشيء` بـ `لاشيء` (`ن == لاشيء` ونوعه `نص`) | `E0437` | احذف الفحص: القيمة موجودة دائماً |
| `اقرأ()` ترجع نصاً فارغاً عند نهاية المدخل (لا يُميَّز من سطر فارغ) | ترجع `نص؟`: `لاشيء` عند النهاية | `س = اقرأ() والا ""` يعطي القديم، أو `اذا س != لاشيء:` |
| `بحث(ق, س)` ترجع `-1` إن لم تجد | ترجع `عدد؟` | `بحث(ق, س) والا -1` يعطي القديم، أو افحص `!= لاشيء` |
| `نظام.بيئة(اسم)` نص فارغ أو `لاشيء` | ترجع `نص؟` | `نظام.بيئة("HOME") والا ""` |
| `من_نص_سي(م)` ترجع `نص` قد يكون `لاشيء` | ترجع `نص؟` | كما سبق |
| `خارجي ... نص_او_لاشيء` | `E0444` | `نص؟` |
| `خارجي ... نص` تُرجع C فيه NULL | خطأ تشغيل `E0443` | صرّح بالإرجاع `نص؟` |
| وسيط اختياري لمدمجة لا تقبله (`طول(س)` و`س` من `نص؟`) | `E0440` | افحصه قبلها أو `س والا ""` |
| `ملفات.*` بمسار أو نص `لاشيء`: خطأ تشغيل `E0372`/`E0373` | لا يُكتب أصلاً: النص لا يكون `لاشيء` | لا شيء |
| `مع` و`بسبب` اسمان عاديان؛ و`تعداد` و`اخطاء` و`عام` و`خاص` كلمات سياقية تكون أسماء | كلمات محجوزة: `E0433` «'مع' كلمة محجوزة ولا تكون اسماً» | غيّر الاسم (`مع_` أو اسماً أدق) |
| كلمة محجوزة اسماً: `والا = 3` يُقبل، و`خاتمه = 3` يعطي `E0026` | `E0433` لكل كلمة محجوزة | غيّر الاسم. و`خطأ` تبقى اسماً عادياً إلا قبل `.` |
| `اطبع(خ)` و`نص(خ)`: الاسم وحده (`غير_موجود`) | الخطأ كله: الاسم، ثم الرسالة، ثم السبب. وخطأ بلا سياق (`ارجع خطأ.س` وحده) يُطبع كما كان | إن احتجت الاسم وحده (مفتاح قاموس، مقارنة نص، ناتج اختبار): `اسم_الخطأ(خ)`. والمقارنة `خ == خطأ.س` و`حالات` لم تتغيرا |
| `حالات خ:` على خطأ بلا `حاله _` ولا كل الأسماء: مقبولة، أو `E0204` في الإسناد | `E0449` يسمّي الأسماء الناقصة | أضف فرعاً لكل اسم ناقص، أو `حاله _:` |
| `حاله خطأ.ممنوع:` على `عدد(...)`، وهي لا ترجعه: مقبولة | `E0451` «'عدد(...)' لا ترجع الخطأ 'ممنوع'» | احذف الفرع |
| `حاله _` بعد كل الأسماء | تحذير `E0452` (استشاري: لا يرفعه `--strict`) | احذفها، أو أبقها لتحمي من خطأ يُضاف لاحقاً |
| `[خطأ تشغيل E0353] ... خطأ لم يُعالَج: غير_موجود` سطراً واحداً | السطر الأول بالسياق، ثم «نشأ في» (كل الأوضاع)، و«ثم» لكل `جرّب` مرّ به (وضع التطوير)، و«بسبب» | أداة تقارن stderr حرفياً تقارن السطر الأول |
| `meem ب.txt` يُشغَّل الملف بأي امتداد (وبلا امتداد) | `E0435` «الملف 'ب.txt' ليس بالامتداد .م: الملف الرئيسي ملف ميم» في التشغيل و`--check` و`build` | غيّر الامتداد إلى `.م`. و`--check --stdin` لا يتأثر |
| `ملفات.المسار_موجود` (دالة خاصة) | أُزيلت | لا شيء: لم تكن عامة |

## ما يُضاف دون كسر

- **النوع الاختياري `ن؟`** لـ `عدد` و`كسر` و`منطقي` و`رمز` و`نص` والقوائم والقواميس والمؤشرات والتعدادات والأخطاء.
  و`اذا س != لاشيء:` يضيّق `س` إلى `ن` داخل الفرع (وبعد `ارجع` في فرع `== لاشيء`)، و`س والا بديل` يعطي القيمة أو البديل.
  وحقل هيكل اختياري يبدأ `لاشيء`. والهيكل والمصفوفة والشريحة لا تكون اختيارية في 0.11.
- **سياق الخطأ:** `ارجع خطأ.اسم بسبب خ مع قيم...`، و`رسالة(خ[, م])` و`سبب(خ)` و`رقم_النظام(خ)` و`اسم_الخطأ(خ)`. والسياق
  في حلقة ثابتة من 64 خطأً لا تُحرَّر ولا تحجز. وأخطاء `ملفات` تحمل المسار ورقم النظام، و`عدد()` و`كسر()` النص الفاسد
  (مقصوصاً بطول ثابت).
- **مجموعات الأخطاء:** يستنتجها المترجم لكل دالة، والصريحة اختيارية: `داله ف(...) !{غير_موجود, ممنوع} نص:`، و`E0453`
  لما يُرجع خارجها.
- **`خاتمه ف() والا خ:`** و**`خاتمه ف() والا _`** و**`خاتمه جرّب ف()`** (كانت `E0022`). و`E0454` لخروج من كتلة `والا`
  فيها، و`E0455` لـ `والا _` في جملة وحدها.
- **التعبير على عدة أسطر** داخل `()` و`[]` و`{}`، والفاصلة الأخيرة في القائمة والقاموس، و`E0434` لقوس لم يُغلق.
- **`والا:`** بلا اسم حين لا يلزم الخطأ.
- **الدالة العامة الضمنية** (معامل بنوع غير كامل كـ `قائمة`) معتمدة رسمياً: نسخة لكل نوع استدعاء
  ([../language/05-functions.md](../language/05-functions.md)). ولا تُؤخذ قيمةً (`E0119`).

ما كان مخططاً لـ 0.11 وانتقل إلى **0.12.0** بقرار المالك: `قارئ` و`كاتب` و`اقرأ_سطر`، والملفات الثنائية و`معلومات`،
والنص بالبايت، و`اعد_حجز`، وجسر `errno` (`نظام.خطأ_النظام()`)، ومؤشرات دوال `!ن`.

## أمثلة

**الغياب:**

```
ق = [3, 5, 7]
م = بحث(ق, 5)
اطبع(م + 1)
```

في 0.10 كان `بحث` يرجع `عدد`. وفي 0.11.0:

```
[خطأ دلالي E0130] سطر 3:8 - العملية '+' غير مدعومة للأنواع 'عدد؟' و 'عدد'
```

والصحيح:

```
ق = [3, 5, 7]
م = بحث(ق, 5)
اذا م != لاشيء:
    اطبع("الموضع ", م + 1)
اطبع(بحث(ق, 9) والا -1)
```

```
الموضع 2
-1
```

**النص لا يكون `لاشيء`:**

```
س نص = لاشيء
```

```
[خطأ دلالي E0252] سطر 1:8 - نوع القيمة المسندة 'لاشيء' لا يطابق النوع المحدد 'نص'
  تلميح: لاشيء لا يكون من النوع 'نص': اكتب النوع الاختياري 'نص؟'
```

**الطباعة:**

```
استورد ملفات
ن = ملفات.اقرأ_ملف("غائب.txt") والا خ:
    اطبع("تعذّرت القراءة: ", خ)
    اطبع("الاسم وحده: ", اسم_الخطأ(خ))
    ""
```

في 0.10 كان السطر الأول `تعذّرت القراءة: غير_موجود`. وفي 0.11.0:

```
تعذّرت القراءة: غير_موجود: غائب.txt (رقم النظام 2: لا ملف ولا مجلد بهذا الاسم)
الاسم وحده: غير_موجود
```

و`عدد("12ب") والا خ: اطبع(خ)` يطبع `صيغة_خاطئة: «12ب» ليس عدداً`.

**الاكتمال:**

```
ن = عدد(ن_نص) والا خ:
    حالات خ:
        حاله خطأ.صيغة_خاطئة:
            0
```

في 0.10 كان `E0204` («كتلة 'والا' يُنتظر منها قيمة»). وفي 0.11.0:

```
[خطأ دلالي E0449] سطر 3:5 - 'حالات' على خطأ 'عدد(...)' لا تذكر: خارج_المدى
  تلميح: أضف  حاله خطأ.خارج_المدى:  أو  حاله _:
```

**خطأ لم يُعالَج:**

```
اخطاء:
    اعداد_فاسد
داله ج(ن نص) !عدد:
    اذا ن == "":
        ارجع خطأ.اعداد_فاسد مع "النص فارغ"
    ارجع 1
داله ب(ن نص) !عدد:
    ارجع جرّب ج(ن) + 1
جرّب ب("")
```

```
[خطأ تشغيل E0353] سطر 9:1 - خطأ لم يُعالَج: اعداد_فاسد: النص فارغ
  نشأ في: سطر 5 (ج)
  ثم:     سطر 8 (ب)
  ثم:     سطر 9
  جرّب ب("")
```

و`--release` (والملف المبني) يطبع «نشأ في» بلا أسطر «ثم».

**الكلمة المحجوزة:**

```
مع = 3
```

```
[خطأ نحوي E0433] سطر 1:1 - 'مع' كلمة محجوزة ولا تكون اسماً
  تلميح: سمّه  مع_  أو اسماً يصف ما فيه.
```
