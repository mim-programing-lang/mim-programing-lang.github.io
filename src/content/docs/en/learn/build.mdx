## Goal

To build a single executable from your program that you can give to someone else, who runs it without installing Meem.

## Explanation

- `meem برنامج.م` compiles the program and runs it straight away, for trying things out.
- `meem build برنامج.م -o برنامج` writes an executable: `./برنامج` runs on its own.
- The file is **static** by default: it contains the whole C library (musl), so it needs nothing from the machine. `--dynamic` builds it dynamically against the system's C library (smaller, and sometimes faster in allocation-heavy programs, but it needs glibc on the machine).
- The program's arguments come after `--` in a direct run (`meem برنامج.م -- سلمى`), and after the file name for a built file (`./برنامج سلمى`).

```sh
meem build عداد.م -o عداد
./عداد
```

## Common mistakes

- A program that uses `خارجي` to call a C library other than the standard C library (such as zlib) cannot be built statically: build it with `--dynamic`, and the library must be installed on the machine that runs it.
- The built file is for Linux x86_64 only. Windows and macOS are not available in 1.0.
