ملخص للصيغ لا شرح لها؛ الشرح في [تعلّم ميم](/learn/) و[فهرس المرجع](/docs/reference/). اطبعها من المتصفح: تُطبع بلا القوائم.

## الأساسيات

| الغرض | الصيغة |
|---|---|
| طباعة | `اطبع("س = ", س)` (بلا فاصل بين القيم) |
| تعليق | `# حتى آخر السطر` |
| متغير ونوعه | `س = 5` · `س عدد64 = 5` (النوع ثابت من أول قيمة) |
| ثابت | `ثابت حد = 100` |
| الأنواع | `عدد64` (و`عدد8` `عدد16` `عدد32`) · `طبيعي8` .. `طبيعي64` و`بايت` · `كسر64` (و`كسر32`) · `نص` · `رمز` · `منطقي` (`صواب`/`خطاء`) |
| اختياري | `ن؟`: قيمة أو `لاشيء` · `اذا س != لاشيء:` · `س والا بديل` |
| صف | `داله قسم(ا عدد64, ب عدد64) (خارج عدد64, باقي عدد64):` · `خ, ب = قسم(17, 5)` · `ن.خارج` |
| تحويل | `نص(5)` · `حلل("5", عدد64) والا 0` · `كسر64(7)` · تضييق يُفحص: `عدد8(ن)` |
| قسمة | `7 / 2` = 3 (صحيحة) · `كسر64(ن) / 2` (صحيح وكسر لا يُخلطان بلا تحويل) · `7 % 2` = 1 |
| إدخال | `س = اقرأ("رسالة: ") والا ""` (`لاشيء` عند نهاية الإدخال) |

## التحكم

| الغرض | الصيغة |
|---|---|
| شرط | `اذا ...:` · `غير ذلك اذا ...:` · `غير ذلك:` |
| منطق | `و` · `او` · `!` |
| حلقة عددية | `لكل ع في مدى(1, 11):` (لا تشمل 11) |
| على قائمة أو قاموس أو نص | `لكل ع في ق:` |
| طالما | `طالما شرط:` |
| خروج / تخطٍّ | `توقف` · `تجاوز` |
| مطابقة | `حالات س:` ثم `حاله قيمة:` و`حاله _:` |

## المجموعات

| الغرض | الصيغة |
|---|---|
| قائمة | `ق = [1, 2, 3]` · `ق قائمة[نص] = []` |
| إضافة / طول / بحث | `اضف(ق, 4)` · `طول(ق)` · `بحث(ق, 2) والا -1` (`لاشيء` إن لم يوجد) |
| ترتيب | `رتب(ق)` · `رتب_ب(ق, دالة_قبل)` |
| قاموس | `د = {"ا": 1}` · `د["ب"] = 2` · `يوجد(د, "ا")` · `احذف(د, "ا")` (ترجع المحذوف) |
| مصفوفة ثابتة | `م مصفوفة[عدد64, 4] = [0, 0, 0, 0]` |
| نصوص | `تقسيم(ن, " ")` · `قص_الفراغات(ن)` · `جزء(ن, 0, 3)` · `يحوي(ن, "س")` · `دمج_نصوص(ا, ب)` |

## الدوال والهياكل والتعداد

| الغرض | الصيغة |
|---|---|
| دالة | `داله اسم(س عدد64, ص نص) عدد64:` ثم `ارجع ...` |
| بلا قيمة | `داله اسم() فراغ:` |
| هيكل | `هيكل نقطة:` ثم حقل في كل سطر: `س عدد64` |
| إنشاء ووصول | `ن = نقطة(1, 2)` · `ن.س` · `ق[0].س += 1` |
| تعداد | `تعداد لون:` ثم عضو في كل سطر · `لون.احمر` · `عدد64(لون.احمر)` = 0 |
| تعداد بحمولة | `دائرة(نق كسر64)` عضواً · `شكل.دائرة(1.0)` · `حاله شكل.دائرة(نق):` |
| معمّم | `داله اكبر[ن](ا ن, ب ن) ن:` · `هيكل زوج[ا, ب]:` · صريحاً: `زوج[نص, عدد64](...)` |
| سمة وقيد | `هيكل نقطة يحقق قابل_للمقارنة:` · `داله اصغر[ن يحقق قابل_للمقارنة](ا ن, ب ن) ن:` |

## الأخطاء

| الغرض | الصيغة |
|---|---|
| أسماء أخطائك | `اخطاء:` ثم اسم في كل سطر |
| دالة قد تفشل | `داله ف() !عدد64:` · `ارجع خطأ.اسم` |
| قيمة بديلة | `ن = ف() والا 0` |
| معالجة بكتلة | `ن = ف() والا خ:` ثم `حالات خ:` وآخر سطر هو القيمة |
| تمرير الفشل | `ن = جرّب ف()` |
| تنظيف عند الفشل وحده | `خاتمه_عند_خطأ ...` |
| أخطاء التشغيل | فهرس خارج القائمة، قسمة على صفر، تجاوز عرض النوع: رمز 3، لا تُعالَج |

## الذاكرة

| الغرض | الصيغة |
|---|---|
| تحرير | `حرر(س)` |
| عند الخروج من الكتلة | `خاتمه حرر(س)` (بعكس الترتيب، عند كل مخرج) |
| ساحة | `س_ = ساحة(الافتراضي)` · `خاتمه اعد(س_)` · `تقسيم(ن, " ", س_)` |
| مؤشر | `م = جديد(نقطة(1, 2))` · `محتوى(م).س` · `حرر(م)` |
| كشف ما لم يُحرَّر | `meem برنامج.م --debug-mem` |
| حجز محلي منسي في دالة | خطأ ترجمة `E0472`: `خاتمه حرر(ن)` أو `ارجع ن` |

## الوحدات وC

| الغرض | الصيغة |
|---|---|
| وحدة قياسية | `استورد رياضيات` ثم `رياضيات.جذر(2.0)` |
| مكتبة مجموعات | `استورد مجموعات` · `كومة_من([3, 1])` · `طابور_من(...)` · `مجموعة_من(...)` |
| ملف بجوارك | `استورد مساعد` (يجلب `مساعد.م`) |
| دالة من C | `خارجي داله طول_c(ن نص) طبيعي64 باسم "strlen"` |
| ذاكرة خام | `خطر:` ثم `احجز_خام(عدد32, 4)` |

## الأوامر

| الغرض | الأمر |
|---|---|
| شغّل | `meem برنامج.م` · بوسائط: `meem برنامج.م -- ا ب` |
| ابنِ ملفاً مستقلاً | `meem build برنامج.م -o برنامج` · حركياً: `--dynamic` |
| افحص بلا تشغيل | `meem --check برنامج.م` · للأدوات: `--check --json` |
| صارم | `--strict` (التحذيرات أخطاء) · `--strict-memory` (ما لا يُثبت تحريره خطأ) |
| ما لا يثبته المجمّع | `--warn-unproven` (خارج الوضع الافتراضي منذ 0.17) |
| كاشف الذاكرة | افتراضي في `meem برنامج.م` · بلا كاشف: `--release` · في الملف المبني: `build --debug` · مع تقرير التسرب: `--debug-mem` |
| منع الخطر | `--no-unsafe` · `--no-ffi` · `--no-system` |
| الإصدار والفحص الذاتي | `meem --version` · `meem --self-test` |
