## المتطلبات

- **لينكس x86_64.** ويندوز وماك غير متاحين بعد.
- **glibc 2.35 أو أحدث**: أوبونتو 22.04 ودبيان 12 وما بعدهما. لا تعمل الحزم على أقدم منها (أوبونتو 20.04، دبيان 11).
- **المجمّع** لا يحتاج بايثون ولا مجمّع C ولا رابطاً. فك الأرشيف يحتاج `xz-utils` (موجودة في سطح المكتب عادة؛ وإلا: `sudo apt install xz-utils`).
- **المحرر deb** يعتمد على `libwebkit2gtk-4.1-0` و`libgtk-3-0` من مستودعات التوزيعة، ويثبّتهما `apt` معه.
- **المحرر AppImage** يحتاج `libfuse2`، أو التشغيل بـ `--appimage-extract-and-run`.
- **الملف الذي يبنيه المجمّع** ساكن لا يطلب شيئاً على الجهاز الذي يشغّله.

## التثبيت والتشغيل

### المجمّع

فك الأرشيف في أي مجلد، ثم شغّل `meem` من داخله. لا تثبيت ولا صلاحيات:

```sh
tar -xJf meem-0.7.0-linux-x86_64.tar.xz
meem-0.7.0-linux-x86_64/meem --version
meem-0.7.0-linux-x86_64/meem برنامج.م
```

يُنقل المجلد كما هو، ولا يُكتب فيه شيء عند التشغيل. الخطوة التالية: [ابدأ](/start/).

### محرر ميم (deb)

لأوبونتو ودبيان:

```sh
sudo apt install ./meem-editor_0.1.0_amd64.deb
```

ثم افتح «محرر ميم» من قائمة التطبيقات، أو بالأمر `meem-editor`.

### محرر ميم (AppImage)

لأي توزيعة فيها glibc 2.35 أو أحدث ومكتبات الواجهة:

```sh
chmod +x meem-editor_0.1.0_amd64.AppImage
./meem-editor_0.1.0_amd64.AppImage
```

إن قال «Cannot mount AppImage» فثبّت `libfuse2`، أو شغّله بـ `./meem-editor_0.1.0_amd64.AppImage --appimage-extract-and-run`.
