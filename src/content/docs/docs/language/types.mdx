**القاعدة.** لكل قيمة نوع يُعرف عند الترجمة. نوع المتغير يثبت من أول إسناد، أو يُكتب بعد اسمه: `س عدد = 3`. لا تحويل
ضمني إلا من `عدد` إلى `كسر` في الحساب والإسناد (../../semantics.md <small>(وثيقة في مستودع المجمّع)</small>).

| النوع | القيمة | ملاحظات |
|---|---|---|
| `عدد` | صحيح بإشارة، 64 بتاً | تجاوز الحد خطأ تشغيل (مع `--wrap-overflow` يلتف) |
| `كسر` | عشري مضاعف الدقة (IEEE-754، 64 بتاً) | `1 / 2` صحيحة، `1 / 2.0` كسرية |
| `نص` | بايتات UTF-8 لا تتغير | الطول والفهرسة بنقاط الترميز؛ `+` بين نصين فقط |
| `رمز` | نقطة ترميز واحدة | `'م'`، وعنصر نص `ن[0]` |
| `منطقي` | `صواب` أو `خطاء` | |
| `لاشيء` | غياب القيمة | يُسند إلى `نص` و`مؤشر[...]` و`مؤشر_خام` |
| `قائمة[ن]` | عناصر من نوع واحد، تكبر | **مرجعية**: `ب = ق` اسمان للقائمة نفسها |
| `قاموس[م, ق]` | مفاتيح `نص` أو `عدد` أو `رمز` أو `منطقي` | مرجعي؛ المرور بترتيب الإدراج |
| `مصفوفة[ن, حجم]` | حجم ثابت | **بالقيمة**: تُنسخ عند الإسناد |
| هيكل | حقول مسمّاة ([الهياكل](/docs/language/structs/)) | بالقيمة |
| `مؤشر[ن]` و`مؤشر_خام` و`شريحة[ن]` | الطبقة المنخفضة ([الطبقة المنخفضة: خطر والشرائح والمؤشرات](/docs/language/low-level/)) | |
| `مخصص` | مخصص ذاكرة ([الذاكرة: المخصصات وخاتمه](/docs/memory/reference/)) | |
| `داله(أنواع) نوع` | مؤشر دالة ([الدوال](/docs/language/functions/)) | منذ 0.7.0 |

أنواع بحجم ثابت (`عدد8`..`عدد32`، `طبيعي8`..`طبيعي64`، `بايت`، `كسر32`) **أنواع تخزين** لا أنواع متغيرات: تُكتب
عنصراً في `مؤشر[...]` و`شريحة[...]` و`مصفوفة[...]` في حقل، وحقلاً في هيكل؛ قراءتها عدد أو كسر، وكتابتها تفحص المدى.

<HBExample id="language/02-types.md#1" />

**القيود المعروفة.** لا أنواع معمَّمة يكتبها المستخدم (`قائمة` بلا نوع عناصر في معامل تُنسخ الدالة لكل نوع، القسم
[الدوال](/docs/language/functions/)). لا تعداد ولا أنواع جمع (مخطط، ../../errors-design.md <small>(وثيقة في مستودع المجمّع)</small>).
مقارنة عدد بكسر فوق 2^53 تقريبية.
