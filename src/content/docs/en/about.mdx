Meem (ميم) is a programming language with Arabic keywords and right-to-left code. The project has two parts: the compiler `meem`, and the Meem editor.

## Status

Meem is in a beta stage before 1.0 (release 0.17.3), and what we ask you to test is in [{betaLabelEn}](/en/beta/). It runs on Linux x86_64; Windows and macOS are not available in 1.0. The [reference documentation](/en/docs/) describes what is in the compiler today, and does not mention what is not.

This English version of the site is a translation for understanding. Meem's code, keywords and compiler messages are Arabic on every page, and the reference pages generated from the Arabic handbook are shown in Arabic until they are translated.
