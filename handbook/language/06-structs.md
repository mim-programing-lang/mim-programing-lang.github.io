# الهياكل

**القاعدة.** `هيكل الاسم:` ثم حقل في كل سطر: `الاسم النوع` أو `الاسم النوع = قيمة_افتراضية` (ذوات القيم الافتراضية في
الآخر). الإنشاء `الاسم(قيم بالترتيب)` أو بالأسماء `الاسم(حقل = قيمة)`. الهيكل **بالقيمة**: الإسناد والتمرير ينسخانه.
والحقل `س.حقل` يُقرأ ويُسند إليه. `هيكل_سي` هيكل بتخطيط C ([10-ffi.md](10-ffi.md)).

```ميم
هيكل نقطة:
    س عدد
    ص عدد = 0

ا = نقطة(3, 4)
ب = ا
ب.س = 10
ج = نقطة(ص = 7, س = 1)
اطبع(ا, " ", ب.س, " ", ج, " ", نقطة(5))
```

```الناتج
نقطة { س: 3, ص: 4 } 10 نقطة { س: 1, ص: 7 } نقطة { س: 5, ص: 0 }
```


**القيود المعروفة.** لا دوال داخل الهيكل (اكتب دوالاً تأخذه معاملاً). هيكل يحوي نفسه بالقيمة خطأ؛ عبر `مؤشر[...]` أو
`قائمة[...]` يصح. الحقل بلا نوع صيغة مهجورة.

**أخطاء محتملة.**

```ميم
هيكل نقطة:
    س عدد
ا = نقطة(1, 2)
```
