الهياكل

صدرت 0.7.0، وهي التنزيل الحالي. تصف هذه الصفحة الإصدار 0.7.

منقول من الكتاب المرجعي: docs/handbook/language/06-structs.md · الإيداع 9961372

القاعدة. هيكل الاسم: ثم حقل في كل سطر: الاسم النوع أو الاسم النوع = قيمة_افتراضية (ذوات القيم الافتراضية في الآخر). الإنشاء الاسم(قيم بالترتيب) أو بالأسماء الاسم(حقل = قيمة). الهيكل بالقيمة: الإسناد والتمرير ينسخانه. والحقل س.حقل يُقرأ ويُسند إليه. هيكل_سي هيكل بتخطيط C (استدعاء C (FFI)).

القيود المعروفة. لا دوال داخل الهيكل (اكتب دوالاً تأخذه معاملاً). هيكل يحوي نفسه بالقيمة خطأ؛ عبر مؤشر[...] أو قائمة[...] يصح. الحقل بلا نوع صيغة مهجورة.
