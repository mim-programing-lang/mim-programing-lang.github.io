ميم أقرب إلى Zig من أي لغة تعليمية: المخصص قيمة تُمرَّر، و`خاتمه` تقابل `defer`، و`!نوع` تقابل `!T`. ولم يكن Zig مثبتاً على جهاز التحليل، فما يخص Zig هنا من وثائقه، **غير مجرَّب**.

## ما يقابل ماذا

| في Zig | في ميم |
|---|---|
| `std.mem.Allocator` يُمرَّر | المخصص وسيطاً أخيراً، ويجوز تركه فيُمرَّر `الافتراضي` |
| `ArenaAllocator` | `ساحة(الاصل)` و`اعد` |
| `FixedBufferAllocator` | `مخزن_ثابت` |
| `GeneralPurposeAllocator` في التنقيح | الكاشف، افتراضي في `meem برنامج.م` وبـ `--debug` في `meem build`؛ و`--debug-mem` يضيف تقرير التسرب |
| `defer` / `errdefer` | `خاتمه` / `خاتمه_عند_خطأ` |
| `!T`، `try`، `catch` | `!نوع`، `جرّب`، `والا` |
| `error{...}` | كتلة `اخطاء:`، ومجموعة الأخطاء في التوقيع اختيارية: `!{غير_موجود, ممنوع} نص` (منذ 0.11.0) |
| `?T` | `ن؟` (منذ 0.11.0)، و`والا` بديلاً |
| `fn max(comptime T: type, ...)` | `داله اكبر[ن](ا ن, ب ن) ن:` بالاستنتاج من الوسائط (منذ 0.15.0) |
| Debug / ReleaseFast | التشغيل المباشر بالكاشف / `meem build` أو `--release` بلا كاشف. وفحص الحدود والتجاوز في الوضعين، و`بلا_فحص` داخل `خطر` موضعياً |

## أين تخالف ميم نموذج Zig (0.17.1)

- **«لا حجز مخفي» قاعدة منذ 0.10.0، باستثناء واحد:** نمو `ن += ذيل` يترك المخزن القديم (تسرب محدود بنحو ضعفي الطول النهائي). وفي 0.9.1 كانت العمليات على «عرض» تحجز نسخاً لا تُعاد.
- **الشريحة والنص:** النص `{مؤشر، طول، مالك}`، والعرض نص على بايتات نص آخر يعيش بعمره.
- **لا `comptime`:** المعمّم بمعاملات نوع تُنسخ لكل تركيبة، والقيد سمة (`سمة` و`يحقق`، منذ 0.17.0)، لا شيفرة تُنفَّذ عند الترجمة.
- **لا مخصصات يكتبها المستخدم**، ولا `resize` ولا محاذاة.
- **الكاشف وقت التشغيل لا وقت الترجمة،** ولا يرى ذاكرة C، و`حرر` لا يتبع ما في داخل الحاوية (لا `deinit` عميق).
- **لا تتبّع كامل للخطأ:** «نشأ في» بسطر أول `ارجع` أرجعه، وسطر «ثم» لكل `جرّب` مرّ به في التشغيل المباشر (منذ 0.11.0)؛ وZig له error return trace كامل في التنقيح.
