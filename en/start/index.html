Getting started

Meem runs on Linux x86_64 today. Windows and macOS are not available in 1.0.

Where it runs

  • The compiler package needs glibc 2.35 or newer (glibc is Linux’s core C library). It was tried on Ubuntu 22.04 and Debian 12.
  • The file you build is static, so it needs no libraries on the machine that runs it. The compiler’s documentation (docs/build.md) says, and this site has not tried it: «tried on Debian 12, Ubuntu 22.04 and Alpine 3.20 (x86-64), and in a container holding no other file at all».
