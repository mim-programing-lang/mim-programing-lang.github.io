## Goal

To define an enum for a known set of fixed values (seasons, directions, the states of a game), and to handle all its values with `حالات` (match).

## Explanation

- `تعداد الاسم:` (enum) at the top level, then one member per line. The name is a new type, and a member is written `الاسم.العضو`.
- A member's number is its position from 0, and `عدد64(العضو)` gives it.
- `لكل ف في فصل:` goes through the members in order.
- `حالات` on an enum must name every member, or add `حاله _:` for the rest. Forgetting a member is a compile error, so no case slips past you.
