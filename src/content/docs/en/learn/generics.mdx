## Goal

To write a function or a struct once so that it works with many types, and to require what you need from the type with a trait.

## Explanation

- A **type parameter** is a name in square brackets after the function's name: `داله اول_او[ن](عناصر قائمة[ن], بديل ن) ن:` (first or a fallback). `ن` stands for some type (since 0.15.0).
- You do not write the type at the call: the compiler **infers** it from the arguments, and copies the function for each type it is called with, so there is no run-time cost.

<Example file="lessons/معمم_اول.م" title="One function for every type" />

- A **generic struct** (since 0.16.0): `هيكل زوج[ا, ب]:` (pair) with fields of types `ا` and `ب`. Construction infers them from the values, or you write them explicitly: `زوج[نص, كسر64](...)`.

<Example file="lessons/معمم_زوج.م" title="A pair of any two types" />

- A **trait** (since 0.17.0) is an ability a type implements, such as `قابل_للمساواة` (equatable, `==`), `قابل_للمقارنة` (comparable, `<` and `>`) and `قابل_للتجزئة` (hashable, a dictionary key). Numbers and strings implement them.
- The **constraint** `[ن يحقق قابل_للمقارنة]` says that the function accepts only types that implement the trait.
- Your struct implements it by declaring it in its definition: `هيكل نسخة يحقق قابل_للمقارنة:`. If you do not write its functions, the compiler derives them field by field, in field order.

<Example file="lessons/معمم_سمة.م" title="The constraint and a derived trait" />
