**القاعدة.** `استورد اسم` في أول الملف يجلب وحدة قياسية أو `اسم.م` بجوار الملف، و`استورد "مسار/ملف"` ملفاً بمسار
نسبي، و`باسم` يعطيها اسماً آخر. ما في الوحدة يُستعمل مؤهَّلاً `وحدة.دالة(...)` أو باسمه وحده إن لم يتعارض.
`خاص` قبل دالة أو هيكل أو ثابت يخفيه عن المستورد. الوحدات القياسية: [المكتبة القياسية](/docs/stdlib/)؛
وقواعد البحث والتهيئة في ../../stdlib-design.md <small>(وثيقة في مستودع المجمّع)</small>.

<HBExample id="language/07-modules.md#1" />

**القيود المعروفة.** الوحدة تُهيَّأ مرة واحدة بترتيب التبعيات. لا استيراد دائري. أمثلة الكتاب ملف واحد؛ الاستيراد بين
الملفات مختبَر في `tests/programs/وحدات/` و`tests/programs/متعدد/`.
