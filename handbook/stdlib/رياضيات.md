# الوحدة `رياضيات`

**مولَّدة** من تعليقات الشرح في `stdlib/رياضيات.م` (`meem --list-module رياضيات --json`). تُستورد بـ`استورد رياضيات`
وتُستدعى دوالها `رياضيات.دالة(...)`. الشرح الأطول وأمثلته في [../../stdlib.md](../../stdlib.md).

## `جذر`

**التوقيع:** `جذر(س كسر)` ← `كسر`

الجذر التربيعي. عدد سالب: خطأ تشغيل.

```ميم
استورد رياضيات
اطبع(رياضيات.جذر(16.0))
```

```الناتج
4.0
```

```ميم
استورد رياضيات
اطبع(رياضيات.جذر(2))
```

```الناتج
1.4142135623730951
```

## `نسق`

**التوقيع:** `نسق(س كسر, خانات عدد, م مخصص)` ← `نص`

الكسر نصاً بعدد ثابت من الخانات بعد الفاصلة (من 0 إلى 100)، مقرَّباً إلى أقرب قيمة؛ خانات خارج المدى: خطأ تشغيل.
التقريب للقيمة المخزَّنة فعلاً (ثنائية)، وعند التساوي التام إلى الخانة الزوجية: نسق(0.125, 2) تعطي 0.12، و
نسق(2.675, 2) تعطي 2.67 لأن 2.675 تُخزَّن أصغر منها بقليل. الناتج يملأ الخانات أصفاراً: نسق(2, 3) تعطي 2.000.
النص من المخصص م إن مُرّر، وإلا من الافتراضي.

المخصص الأخير اختياري: إن تُرك فالافتراضي.

```ميم
استورد رياضيات
اطبع(رياضيات.نسق(3.14159, 2))
```

```الناتج
3.14
```

```ميم
استورد رياضيات
اطبع(رياضيات.نسق(2, 3))
```

```الناتج
2.000
```

```ميم
استورد رياضيات
اطبع(رياضيات.نسق(-1234.5678, 1))
```

```الناتج
-1234.6
```

```ميم
استورد رياضيات
اطبع(رياضيات.نسق(0.125, 2))
```

```الناتج
0.12
```

```ميم
استورد رياضيات
اطبع(رياضيات.نسق(2.5, 0))
```

```الناتج
2
```

## `باي` (ثابت)

النوع: `كسر`. نسبة محيط الدائرة إلى قطرها. مثال: باي  ←  3.141592653589793

```ميم
استورد رياضيات
اطبع(رياضيات.نسق(رياضيات.باي, 5), " ", رياضيات.نسق(2 * رياضيات.باي * 3.0, 2))
```

```الناتج
3.14159 18.85
```

## `اويلر` (ثابت)

النوع: `كسر`. أساس اللوغاريتم الطبيعي (عدد أويلر). مثال: اويلر  ←  2.718281828459045

```ميم
استورد رياضيات
اطبع(رياضيات.نسق(رياضيات.اويلر, 5), " ", رياضيات.نسق(رياضيات.لوغاريتم(رياضيات.اويلر), 1))
```

```الناتج
2.71828 1.0
```
