## Goal

To map a key to a value, and to go through the keys in the order they were inserted.

## Explanation

- A **dictionary** maps each **key** to a value: `{"سارة": 30}`. You reach the value through its key: `اعمار["سارة"]`.
- Assigning a value to a new key adds it to the dictionary.
- `لكل اسم في اعمار:` goes through the keys in insertion order. `مفاتيح(ق)` (keys) returns them as a list in the same order.
