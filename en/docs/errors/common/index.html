This page has not been translated into English yet, so it is shown in Arabic. Code and Meem keywords are Arabic on every page.

صدرت 0.17.3، وهي التنزيل الحالي. تصف هذه الصفحة الإصدار 0.17.

منقول من الكتاب المرجعي: docs/handbook/errors/common.md · الإيداع 434e13f

لكل خطأ مثال يسببه (الناتج كما يطبعه المجمّع، برمز خروجه) ومثال يصلحه؛ كلاهما يُشغَّل في tests/test_docs.py. الفهرس الكامل لكل رسالة في فهرس رسائل الأخطاء والتحذيرات. رمز 2: خطأ ترجمة لم يُنفَّذ معه شيء؛ رمز 3: خطأ تشغيل، ويبقى ما طُبع قبله.
