**لينكس x86-64 الآن.** ويندوز وماك لاحقاً: غير مدعومَين اليوم.

:::caution[أين يعمل]
- **أداة البناء** (حزمة المجمّع) تحتاج glibc 2.35 أو أحدث. التوزيعات المجرَّبة: أوبونتو 22.04 ودبيان 12.
- **الملف الذي تبنيه** ساكن. نص وثيقة المجمّع (`docs/build.md`)، لا تجربة هذا الموقع: «جُرّب على دبيان 12 وأوبونتو 22.04 وألباين 3.20 (x86-64)، وفي حاوية ليس فيها ملف واحد غيره».
- لينكس x86-64 الآن. ويندوز وماك لاحقاً.
:::


## 1. احصل على المجمّع

نزّل أرشيف المجمّع من صفحة [التحميل](/download/)، وتحقق من بصمته هناك، ثم فكّه:

```sh
tar -xJf meem-0.7.0-linux-x86_64.tar.xz
export PATH="$PWD/meem-0.7.0-linux-x86_64:$PATH"
```

المجلد فيه المجمّع وكل ما يلزمه، لا يحتاج بايثون ولا تثبيتاً. السطر الثاني يجعل الأمر `meem` متاحاً في هذه الطرفية؛ ولتبقى في كل طرفية أضفه إلى ملف إعداد صدفتك (مثل `~/.bashrc`) بالمسار الكامل للمجلد.

## 2. تحقق من التثبيت

```sh
meem --version
meem --self-test
```

الأمر الثاني يطبع سطراً واحداً بالنجاح، أو السبب إن فشل.

## 3. شغّل أول برنامج

اكتب في ملف اسمه `مرحبا.م`:

```ميم
اطبع("مرحبا يا عالم")
```

ثم:

```sh
meem مرحبا.م
```

## 4. ابنِ ملفاً يعمل وحده

```sh
meem build مرحبا.م -o مرحبا
./مرحبا
```

الناتج ملف تنفيذي مستقل لا يحتاج ميم ولا بايثون. التفصيل في درس [ابنِ برنامجك](/docs/build/).
