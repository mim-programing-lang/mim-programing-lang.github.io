المصدر: `CHANGELOG.md` <small>(وثيقة في مستودع المجمّع)</small> (قسم 0.12.0)، والتصميم `design-numerics.md` <small>(وثيقة في مستودع المجمّع)</small>
بقرارات المالك. **قبل 1.0 أفضل تصميم يفوز على التوافق** (`deprecation-policy.md` <small>(وثيقة في مستودع المجمّع)</small>): ما يكسر هنا
يكسر بلا طبقة توافق، **ولا `--fix` للمستخدم** (قرار المالك). وكل رسالة جديدة تقول البديل في نصها وتلميحها.

الكسر الأكبر: **الأعداد بأحجامها، والاسمان `عدد` و`كسر` أُزيلا.** يُكتب `عدد64` و`كسر64` في الغالب، وبقية الأحجام حيث يلزم
الحجم (ملفات ثنائية، C، ذاكرة).

## ما يتغير

| كان في 0.11 | صار في 0.12.0 | ما تفعله |
|---|---|---|
| `س عدد = 3`، `داله ف(ك كسر) كسر` | `E0456` «النوع 'عدد' أُزيل: اكتب حجمه، عدد64 في الغالب» | `عدد64`، `كسر64` |
| `حجم` في `خارجي` (`size_t`) | `E0456` | `طبيعي64`؛ وعدد64 يُمرَّر إليه ويُفحص أنه غير سالب |
| `عدد("12") والا 0`، `كسر("2.5") والا 0.0` | `E0470` «'عدد(...)' أُزيلت مع اسم النوع: اكتب حلل(النص, عدد64)» | `حلل("12", عدد64) والا 0` |
| `عدد(3.9)` (بتر) | `E0470` | `رياضيات.بتر(3.9)` (أو `ارضيه`، `سقف`، `قرب`) بعد `استورد رياضيات` |
| `عدد(صواب)`، `عدد(لون.احمر)`، `كسر(3)` | `E0470` | `عدد64(صواب)`، `عدد64(لون.احمر)`، `كسر64(3)` |
| `7 * 2.5` بمتغير صحيح (`ن * 2.5`) | `E0458` «'*' بين 'عدد64' و'كسر64': لا نوع يسعهما» | `كسر64(ن) * 2.5`. والحرفيتان معاً تبقيان مقبولتين (`7 * 2.5`) |
| متغير صحيح حيث يُنتظر كسر: `ارجع ن` من دالة `كسر64`، `ك كسر64 = ن`، `جذر_c(ن)` لمعامل خارجي `كسر64` | قبلُ يصير كسراً ضمنياً؛ الآن عدم تطابق النوع (`E0246`، `E0252`، `E0179`، `E0180`) | `كسر64(ن)`. والحرفية الصحيحة تبقى مقبولة (`ك كسر64 = 3`) |
| `ب بايت = ن` (`ن` من عدد64)، و`ك[0] = ن` في كتلة `عدد32` | قبلُ تضييق ضمني بفحص وقت التشغيل؛ الآن `E0459` أو `E0410` | `طبيعي8(ن)`، `عدد32(ن)`: التضييق صريح ويُفحص مداه |
| `بلا_فحص ك[0] = ن` في كتلة `بايت` (قطع ضمني) | `E0410`: `بلا_فحص` لا يضيّق ضمنياً | `ك[0] = بلا_فحص طبيعي8(ن)` يقطع، أو `ملتف(ن, طبيعي8)` |
| `ب بايت = 300`، `ك[0] = -1` في `طبيعي64` | قبلُ خطأ تشغيل؛ الآن خطأ ترجمة `E0457` | قيمة في المدى، أو نوع أعرض |
| `قائمة[عدد32]` | قبلُ `E0160` (نوع تخزين فقط) | يُقبل: الأحجام أنواع قيم كاملة |
| `اطبع(ك)` لـ `كسر32` قيمته 0.1 | `0.10000000149011612` | `0.1` (أقصر تمثيل بـ 32 بتاً) |
| `--wrap-overflow` | خطأ سطر الأوامر «أُزيل في 0.12.0» | `جمع_ملتف` وأخواتها في الموضع، أو `--fast` للبرنامج كله |
| رسالة التجاوز «تجاوز العدد الصحيح حدود 64 بت ...» (`E0341`) | «تجاوز النوع 'عدد64' في العملية '+'» | أداة تقارن النص تقارن المعرّف |
| `عشوائي.كسر()` | أُزيلت | `عشوائي.نسبة()` |
| `رسالة(خ)` نص، فارغ بلا رسالة | `نص؟`: `لاشيء` بلا رسالة | `رسالة(خ) والا ""` |
| `مسارات.اسم_الملف` و`المجلد` و`الامتداد` نص فارغ للغياب | `نص؟` | `... والا ""`، أو `== لاشيء` |
| دالة باسم `حلل` أو `ملتف` أو `جمع_ملتف`... | تحجب المدمجة الجديدة بتحذير `E0276` | لا شيء، أو اسم آخر (يلزم مع `--strict`) |
| `ق.اضف(3)` على قائمة | قبلُ `E0158` «لا يملك حقولاً» | يُقبل: الاستدعاء الموحَّد `ق.اضف(3)` = `اضف(ق, 3)` |
| خارجي بمعامل `عدد32` قيمته عدد64 | قبلُ فحص وقت التشغيل | يُطلب `عدد32(س)`؛ والحرفية تتكيف (`مطلق32(-7)`) |

## ما يُضاف دون كسر

- **الأنواع العشرة**: `عدد8/16/32/64`، `طبيعي8/16/32/64` (و`بايت`)، `كسر32/64`، بالتوسيع الآمن الضمني، والتحويل باسم النوع
  (`عدد32(س)` يفحص المدى)، والحرفية تتكيف مع النوع المطلوب وتُفحص عند الترجمة.
- **`حلل(النص, النوع)`** ترجع `!النوع` (`صيغة_خاطئة`، `خارج_المدى` بسياقهما).
- **الأُسّ في الحرفيات**: `1.5e10`، `6.674e-11`.
- **`--fast`**: إصدار سريع، التجاوز يلتف (معرَّف)، ولا فحص لحدود فهرسة القوائم والمصفوفات (الخطر الوحيد).
- **الالتفاف الصريح**: `جمع_ملتف` `طرح_ملتف` `ضرب_ملتف`، و`ملتف(س, النوع)` للقطع.
- **الاستدعاء الموحَّد** `س.ف(...)` = `ف(س, ...)`، ودوال الوحدات المستوردة باسمها القصير؛ والالتباس خطأ ترجمة (`E0464`).
- **`رياضيات.بتر`**.
- **الخيوط عبر `خارجي`** تُبنى (كان `pthread_create` يكسر `meem build`)، وما تضمنه اللغة معها في
  `memory-safety.md` <small>(وثيقة في مستودع المجمّع)</small> القسم 6.

## أمثلة

```ميم nocheck
داله متوسط(ق قائمة[عدد]) كسر:
    مجموع = 0
    لكل س في ق:
        مجموع += س
    ارجع مجموع / طول(ق)
```

في 0.11 يعمل (الصحيح يصير كسراً). وفي 0.12.0: `E0456` لـ `عدد` و`كسر`، ثم بعد كتابة الحجمين `E0458` على `مجموع / طول(ق)`
لو كان مجموع كسراً. والصحيح:

```ميم nocheck
داله متوسط(ق قائمة[عدد64]) كسر64:
    مجموع = 0
    لكل س في ق:
        مجموع += س
    ارجع كسر64(مجموع) / كسر64(طول(ق))
```

```ميم nocheck
ن = حلل(اقرأ() والا "", عدد64) والا 0      # كان: عدد(اقرأ() والا "") والا 0
ب = طبيعي8(ن)                              # خارج 0..255: خطأ تشغيل E0328
```

## الأدوات

`scripts/migrate-numerics.py` سكربت المشروع الداخلي الذي رحّل المكتبة والبرامج المرجعية والكتاب: يطبّق ما يقوله المجمّع
نفسه (`--check --json` مع `MEEM_MIGRATION_FIXES=1` يرفق بـ `E0456` و`E0470` تعديلاتهما). ليس `--fix`: لا يرحّل ما يحتاج
قراراً (`E0458`، `E0459`، `E0410`)، ويسرده للمراجعة.
