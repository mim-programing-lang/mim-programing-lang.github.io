## Goal

To store a value under a name and calculate with it, and to tell integer division from fractional division.

## Explanation

- A **variable** is a name you give to a value: `الطول = 7`.
- Every value has a **type**: `7` is an integer of type `عدد64` (64-bit integer), `3.5` is a float of type `كسر64` (64-bit float), and `"ميم"` is text of type `نص` (string). The number in the type name is its size in bits. You do not write the type yet: Meem knows it from the value.
- A variable's type is set by the first value you give it, or you write it after the name: `س عدد64 = 3`.
- Division `/` between two integers gives an integer: it drops what comes after the decimal point (rounding toward zero): `7 / 2` is `3`.
- Meem does not mix an integer and a float without a conversion, so it never hides which one you meant: to get `3.5` from the variable `الطول`, convert it first, `كسر64(الطول) / 2`. A number written directly takes the type it needs, so `7 / 2.0` gives `3.5`.

Other mistakes:

- Dividing an integer variable by a float without a conversion: `الطول / 2.0` is error [E0458](/en/docs/errors/catalog/#E0458) «لا نوع يسعهما» (no type holds both); write `كسر64(الطول) / 2`.
- Naming a variable after a builtin function, because that name is reserved: `طول = 7` is syntax error [E0474](/en/docs/errors/catalog/#E0474) «'طول' اسم دالة مدمجة ولا يكون اسم متغير أو معامل» ('طول' is a builtin function name and cannot be a variable or parameter name).
