**الدوال التي تحجز** تأخذ المخصص آخر وسيط اختيارياً. **ما قد يفشل** (تحويل نص إلى عدد، الملفات) يرجع `!نوع`
ويُعالَج بـ`جرّب` أو `والا` ([../language/13-errors.md](../language/13-errors.md)).

**الملف المفتوح: القارئ والكاتب** (منذ 0.14.0، في `ملفات`). `افتح_للقراءة` و`افتح_للكتابة` و`افتح_للالحاق` ترجع مقبضاً مرجعياً (`قارئ` أو `كاتب`) يُغلق بـ `ملفات.اغلق`؛ و`اقرأ_سطر` ترجع السطر بلا نهايته أو `لاشيء` عند نهاية الملف؛ و`اكتب`/`اكتب_سطر` تدمج قيمها كـ `دمج_نصوص` (لا قوائم ولا هياكل)؛ والبايتات بـ `اقرأ_بايتات`/`اكتب_بايتات` في `شريحة[بايت]`. الاستعمال بعد الإغلاق بأي اسم خطأ تشغيل `E0494`. وفي `نظام`: `خطأ_النظام()` لدوال C عبر `خارجي`.

```ميم
استورد ملفات
داله اكتب_ثم_اقرأ(مسار نص) !عدد64:
    ك = جرّب ملفات.افتح_للكتابة(مسار)
    جرّب ملفات.اكتب_سطر(ك, "سطر ", 1)
    جرّب ملفات.اكتب_سطر(ك, "سطر ", 2)
    جرّب ملفات.اغلق(ك)
    ق = جرّب ملفات.افتح_للقراءة(مسار)
    خاتمه ملفات.اغلق(ق)
    عدد_ = 0
    طالما صواب:
        سطر = جرّب ملفات.اقرأ_سطر(ق)
        اذا سطر == لاشيء:
            توقف
        خاتمه حرر(سطر)
        عدد_ += 1
    جرّب ملفات.احذف_ملف(مسار)
    ارجع عدد_
اطبع(اكتب_ثم_اقرأ("مثال_الكتاب.txt") والا -1)
```

```الناتج
2
```

**كومة وطابور ومجموعة، وتحريرها** (منذ 0.17.0، في `مجموعات`). الثلاثة هياكل معمَّمة تحمل قائمة أو قاموساً،
فتُنشأ بـ`كومة_من` و`طابور_من` و`مجموعة_من`، و**ذاكرتها تعود بـ`حرر_كومة` و`حرر_طابور` و`حرر_مجموعة`**:
كلٌّ تحرّر حقلها (القائمة أو الجدول). الهيكل يُمرَّر بالقيمة والحقل مرجعي، فالتحرير يصيب الأصل؛ ولا تُستعمل
الحاوية بعده (الكاشف يرى الاستعمال بعد التحرير). وما حُجز بـ`جديد` يلزمه تحرير الخانة كذلك:
`حرر_كومة(محتوى(ك))` ثم `حرر(ك)`. وقائمة من مخصص غير الافتراضي تُحرَّر باليد: `حرر(ك.عناصر, م)`.

```ميم
استورد مجموعات
ك = مجموعات.كومة_من([1, 2, 3])
اطبع(مجموعات.اعلى(ك) والا -1, " ", مجموعات.طول_كومة(ك))
مجموعات.حرر_كومة(ك)

ج = مجموعات.مجموعة_من(["الف", "باء", "الف"])
اطبع(مجموعات.طول_مجموعة(ج), " ", مجموعات.يحوي_عنصر(ج, "باء"))
مجموعات.حرر_مجموعة(ج)
```

```الناتج
3 3
2 صواب
```
