## Goal

To choose the structure that fits what you are doing: the stack for the last thing in, the queue for the first thing in, and the set for membership without repetition.

## Explanation

- After `استورد مجموعات` (import collections), you build the structure from a list: `كومة_من` (stack from), `طابور_من` (queue from) and `مجموعة_من` (set from). The element type is inferred from the list, because they are generic structs written in Meem (since 0.17.0).
- What only reads takes the structure itself (`اعلى` top, `طول_كومة` stack length, `يحوي_عنصر` contains), and what changes it takes a **pointer** to it (`ادفع` push, `اسحب` pop, `اضف_اليها` add). That is why it is built with `جديد(...)` (new) and read with `محتوى(...)` (contents).
- Taking from an empty structure returns `لاشيء` (nothing), so the result of `اسحب` and `اعلى` has the type `ن؟`: give it a fallback with `والا` (else).
- **Freeing** (since 0.17.2): `حرر_كومة`, `حرر_طابور` and `حرر_مجموعة` give the structure's memory back, so it is not used afterwards. For one allocated with `جديد`, free its contents and then the slot: write `خاتمه حرر(ك)` and then `خاتمه مجموعات.حرر_كومة(محتوى(ك))` next to the line that builds it; `خاتمه` runs in reverse order.

The examples here were run with the `--debug-mem` option, and the line «كل الخانات حُرّرت» (all slots were freed) at their end says that nothing was left.

## Exercise

Count the different words in a sentence with `تقسيم` (split) and then `مجموعة_من`. Then keep the squares a player passed through on a board in a set of a struct `مربع` (square) that implements `قابل_للتجزئة`, and ask whether the player passed through a given square. Free everything you built, so that `--debug-mem` prints no report (the parts from `تقسيم` go in an arena, given back at once).
