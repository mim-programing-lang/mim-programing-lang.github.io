## Goal

To choose the structure that fits what you are doing: the stack for the last thing in, the queue for the first thing in, and the set for membership without repetition.

## Explanation

- After `استورد مجموعات` (import collections), you build the structure from a list: `كومة_من` (stack from), `طابور_من` (queue from) and `مجموعة_من` (set from). The element type is inferred from the list, because they are generic structs written in Meem (since 0.17.0).
- What only reads takes the structure itself (`اعلى` top, `طول_كومة` stack length, `يحوي_عنصر` contains), and what changes it takes a **pointer** to it (`ادفع` push, `اسحب` pop, `اضف_اليها` add). That is why it is built with `جديد(...)` (new) and read with `محتوى(...)` (contents).
- Taking from an empty structure returns `لاشيء` (nothing), so the result of `اسحب` and `اعلى` has the type `ن؟`: give it a fallback with `والا` (else).

**The stack:** the last thing in is the first thing out.
