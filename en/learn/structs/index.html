9. Structs

Meem 0.17.3 is out and is the current download. This page describes release 0.17.
Level: BeginnerLesson 9 of 22Time: about 20 minutesPrerequisites: Functions, Lists

Goal

Section titled “Goal”

To gather the data of one thing in a struct.

Explanation

Section titled “Explanation”
  • A struct is a type you define yourself, made of fields: each field has a name and a type, one field per line.
  • You create a value of it by writing its name, then the values in field order: طالب("ليلى", 91).
  • ط.اسم reads the field اسم from the value ط.
