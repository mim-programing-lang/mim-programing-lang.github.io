# استدعاء C (FFI)

**القاعدة.** `خارجي "مكتبة" داله الاسم(المعامل نوع_C, ...) نوع_C باسم "اسم_C"` في المستوى الأعلى يصرّح بدالة من مكتبة C؛
بلا مكتبة فهي من مكتبة C نفسها. الأنواع في التوقيع أنواع C (جدولها في [01-lexicon.md](01-lexicon.md)). الرمز يُفحص قبل
التشغيل: مفقود خطأ ترجمة برمز 2. `--no-ffi` يمنع `خارجي` في برنامج المستخدم (لا في المكتبة القياسية). التفصيل في
[../../stdlib-design.md](../../stdlib-design.md) و[../../low-level.md](../../low-level.md).

- `نص` يُمرَّر منتهياً بصفر؛ ونص ترجعه C يُنسخ (`نص_مملوك`: يُنسخ ثم يُحرَّر الأصل بـ`free`). و`نص` لا يكون NULL: C ترجعه
  NULL خطأ تشغيل (`E0443`)؛ و`نص؟` (منذ 0.11.0، بدل `نص_او_لاشيء`) يقبل NULL معاملاً وإرجاعاً، ويكون لاشيء.
- الأعداد بأحجامها: القيمة خارج مدى `عدد32` خطأ تشغيل عند الاستدعاء.
- منذ 0.7.0: `هيكل_سي` (تخطيط C، `حجم_النوع` يطابق `sizeof`) و`مؤشر[هيكل_سي]` في التوقيع، و`نص_سي` (`char *`
  بلا نسخ، مع `نص_سي(ن[, م])` و`من_نص_سي(خ)`)، ودالة ميم تُمرَّر باسمها إلى C (استدعاء عكسي).
- **الخيوط عبر `خارجي`** (`pthread_create`، `thrd_create`) تعمل مباشرةً ومبنيةً (منذ 0.12.0)، لكن حالة وقت التشغيل غير آمنة
  للخيوط والسباق سلوك غير معرَّف: ما يجوز وما لا يجوز في [../../memory-safety.md](../../memory-safety.md) القسم 6.

```ميم
خارجي "m" داله جذر(س كسر64) كسر64 باسم "sqrt"
خارجي داله طول_c(ن نص) طبيعي64 باسم "strlen"
هيكل_سي رأس:
    نوع طبيعي8
    طول عدد32
اطبع(جذر(2.0), " ", طول_c("ميم"), " ", حجم_النوع(رأس))
```

```الناتج
1.4142135623730951 6 8
```


**المقبض المبهم** (منذ 0.14.0): `هيكل_سي الاسم` بلا نقطتين ولا حقول نوع C مبهم (كـ `struct FILE;` في C)، يُستعمل `مؤشر[الاسم]` وحده، فمقبض ملف ومقبض نافذة نوعان لا يختلطان؛ وبالقيمة أو `محتوى` أو `حجم_النوع` خطأ `E0478`.

```ميم
هيكل_سي ملف_c
خارجي داله افتح(مسار نص, وضع نص) مؤشر[ملف_c] باسم "fopen"
خارجي داله اغلق(م مؤشر[ملف_c]) عدد32 باسم "fclose"
م = افتح("/etc/hostname", "r")
اذا م != لاشيء:
    اطبع(اغلق(م))
```

```الناتج
0
```


**الهيكل بالقيمة لا يُمرَّر إلى C** (منذ 0.14.0 خطأ برسالته `E0477`، لا نتيجة خاطئة صامتة): قواعد ABI لتمرير الهيكل بالقيمة لا يكتبها المجمّع بعد؛ مرّر مؤشراً، أو اكتب غلافاً صغيراً في C.

```ميم
هيكل_سي زوج:
    ا عدد32
    ب عدد32
خارجي داله قسم_c(ا عدد32, ب عدد32) زوج باسم "div"
```

```خطأ
رمز الخروج: 2
--- stdout ---
--- stderr ---

[خطأ دلالي E0477] سطر 4:36 - الهيكل 'زوج' بالقيمة في نوع الإرجاع للدالة الخارجية 'قسم_c': ميم لا تمرّر الهياكل إلى C بالقيمة
   4 | خارجي داله قسم_c(ا عدد32, ب عدد32) زوج باسم "div"
     |                                    ^~~
  تلميح: مرّر مؤشراً إليه: مؤشر[زوج]، والهيكل بتخطيط C (هيكل_سي). وإن كانت دالة C تأخذه أو ترجعه بالقيمة فاكتب لها غلافاً صغيراً في C يأخذ مؤشراً ويكتب فيه.
```


**القيود المعروفة.** لا دوال متغيرة عدد الوسائط (`printf`). القوائم والقواميس والهياكل والصفوف بالقيمة لا تُمرَّر. و`long` في C يقابل `عدد64` في لينكس x86-64 وحده (وفي ويندوز `long` 4 بايتات: `عدد32`). دالة ميم إلى
C تُمرَّر باسمها لا بمتغير. C التي تحتفظ بمؤشر نص بعد رجوعها مسؤولية كاتب التصريح.

**أخطاء محتملة.**

```ميم
خارجي "m" داله غريبة(س كسر64) كسر64 باسم "no_such_function_xyz"
اطبع(غريبة(1.0))
```

```خطأ
رمز الخروج: 2
--- stdout ---
--- stderr ---

[خطأ توليد الكود E0416] سطر 1:1 - الرمز 'no_such_function_xyz' غير موجود في المكتبة 'm' ولا في مكتبة C (تصريح الدالة الخارجية 'غريبة')
   1 | خارجي "m" داله غريبة(س كسر64) كسر64 باسم "no_such_function_xyz"
     | ^~~~~
  تلميح: تأكد من اسم الدالة في C بعد 'باسم'، ومن اسم المكتبة بعد 'خارجي'.
```
