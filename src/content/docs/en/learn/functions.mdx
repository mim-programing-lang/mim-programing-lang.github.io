## Goal

To write a function with parameters and a return type, and to call it after defining it.

## Explanation

- A **function** is a named group of instructions. It starts with a line such as `داله مساحة(ط كسر64, ع كسر64) كسر64:`, followed by its body indented underneath.
- Between the parentheses are the **parameters**: the name and type of each value the function takes. After the parentheses comes the **return type**: the type of what it returns. A function that returns no value has the return type `فراغ` (void).
- `ارجع` (return) ends the function and returns the value written after it.
- A function is called **after** its definition in the file.
