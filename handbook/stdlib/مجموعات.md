# الوحدة `مجموعات`

**مولَّدة** من تعليقات الشرح في `stdlib/مجموعات.م` (`meem --list-module مجموعات --json`). تُستورد بـ`استورد مجموعات`
وتُستدعى دوالها `مجموعات.دالة(...)`. الشرح الأطول وأمثلته في [../../stdlib.md](../../stdlib.md).

## `كومة_من`

**التوقيع:** `كومة_من(عناصر قائمة[ن])` ← `كومة[ن]`

كومة من عناصر (وللفارغة مرّر قائمة فارغة مكتوبة النوع: ق قائمة[عدد64] = []).
نوع العنصر يُستنتج من القائمة، فلا يُكتب صراحةً.

```ميم
استورد مجموعات
اطبع(طول_كومة(كومة_من([1, 2, 3])))
```

```الناتج
3
```

## `طابور_من`

**التوقيع:** `طابور_من(عناصر قائمة[ن])` ← `طابور[ن]`

طابور من عناصر، أولها مقدمة الطابور.

```ميم
استورد مجموعات
اطبع(طول_طابور(طابور_من([1, 2])))
```

```الناتج
2
```

## `مجموعة_من`

**التوقيع:** `مجموعة_من(عناصر قائمة[ن])` ← `مجموعة[ن]`

مجموعة من عناصر قائمة (المكرر يُدمج). يطلب أن يحقق ن سمة «قابل_للتجزئة».

```ميم
استورد مجموعات
اطبع(طول_مجموعة(مجموعة_من([3, 1, 3])))
```

```الناتج
2
```

## `ادفع`

**التوقيع:** `ادفع(ك مؤشر[كومة[ن]], س ن)` ← `فراغ`

يضع س في أعلى الكومة.
استعمال: ك = جديد(كومة_من([1]))  ثم  ادفع(ك, 2)  فتصير قمتها 2

## `اسحب`

**التوقيع:** `اسحب(ك مؤشر[كومة[ن]])` ← `ن؟`

يسحب أعلى الكومة ويرجعه، أو لاشيء إن كانت فارغة.
استعمال: ك = جديد(كومة_من([1, 2]))  ثم  اسحب(ك) والا -1  يعطي 2

## `اعلى`

**التوقيع:** `اعلى(ك كومة[ن])` ← `ن؟`

أعلى الكومة بلا سحب، أو لاشيء.

```ميم
استورد مجموعات
اطبع(مجموعات.اعلى(كومة_من([1, 2, 3])) والا -1)
```

```الناتج
3
```

## `طول_كومة`

**التوقيع:** `طول_كومة(ك كومة[ن])` ← `عدد64`

عدد ما في الكومة.

```ميم
استورد مجموعات
اطبع(مجموعات.طول_كومة(كومة_من([5])))
```

```الناتج
1
```

## `حرر_كومة`

**التوقيع:** `حرر_كومة(ك كومة[ن])` ← `فراغ`

يعيد ذاكرة الكومة إلى المخصص الافتراضي: يحرّر قائمة عناصرها، فلا تُستعمل الكومة بعده.
استعمال: ك = كومة_من([1, 2])  ثم  حرر_كومة(ك)  (وللمحجوزة بـ«جديد»: حرر_كومة(محتوى(ك)) ثم حرر(ك))

## `ادفع_خلفاً`

**التوقيع:** `ادفع_خلفاً(ط مؤشر[طابور[ن]], س ن)` ← `فراغ`

يضع س في آخر الطابور.
استعمال: ط = جديد(طابور_من([1]))  ثم  ادفع_خلفاً(ط, 2)  فيصير آخره 2

## `اسحب_اماماً`

**التوقيع:** `اسحب_اماماً(ط مؤشر[طابور[ن]])` ← `ن؟`

يسحب أول الطابور ويرجعه، أو لاشيء إن كان فارغاً.
استعمال: ط = جديد(طابور_من([1, 2]))  ثم  اسحب_اماماً(ط) والا -1  يعطي 1

## `طول_طابور`

**التوقيع:** `طول_طابور(ط طابور[ن])` ← `عدد64`

عدد ما في الطابور.

```ميم
استورد مجموعات
اطبع(مجموعات.طول_طابور(طابور_من([5, 6])))
```

```الناتج
2
```

## `حرر_طابور`

**التوقيع:** `حرر_طابور(ط طابور[ن])` ← `فراغ`

يعيد ذاكرة الطابور إلى المخصص الافتراضي: يحرّر قائمة عناصره، فلا يُستعمل الطابور بعده.
استعمال: ط = طابور_من([1, 2])  ثم  حرر_طابور(ط)

## `اضف_اليها`

**التوقيع:** `اضف_اليها(ج مؤشر[مجموعة[ن]], س ن)` ← `فراغ`

يضيف س إلى المجموعة (الموجود لا يتكرر).
استعمال: ج = جديد(مجموعة_من([1]))  ثم  اضف_اليها(ج, 2)  فيصير طولها 2

## `يحوي_عنصر`

**التوقيع:** `يحوي_عنصر(ج مجموعة[ن], س ن)` ← `منطقي`

هل س في المجموعة؟

```ميم
استورد مجموعات
اطبع(مجموعات.يحوي_عنصر(مجموعة_من([1, 2]), 2))
```

```الناتج
صواب
```

## `احذف_منها`

**التوقيع:** `احذف_منها(ج مؤشر[مجموعة[ن]], س ن)` ← `منطقي`

يحذف س إن كان فيها؛ يرجع هل كان موجوداً.
استعمال: ج = جديد(مجموعة_من([1]))  ثم  احذف_منها(ج, 1)  يعطي صواب

## `طول_مجموعة`

**التوقيع:** `طول_مجموعة(ج مجموعة[ن])` ← `عدد64`

عدد عناصر المجموعة.

```ميم
استورد مجموعات
اطبع(مجموعات.طول_مجموعة(مجموعة_من([1, 1])))
```

```الناتج
1
```

## `حرر_مجموعة`

**التوقيع:** `حرر_مجموعة(ج مجموعة[ن])` ← `فراغ`

يعيد ذاكرة المجموعة إلى المخصص الافتراضي: يحرّر جدولها، فلا تُستعمل المجموعة بعده.
استعمال: ج = مجموعة_من([1, 2])  ثم  حرر_مجموعة(ج)

## `كومة` (هيكل)

`عناصر قائمة[ن]`

كومة: آخر ما يدخل أول ما يخرج. عناصرها قائمة، آخرها قمة الكومة.

## `طابور` (هيكل)

`عناصر قائمة[ن]`

طابور: أول ما يدخل أول ما يخرج. يُسحب من المقدمة بـ«احذف_اول».

## `مجموعة` (هيكل)

`جدول قاموس[ن, منطقي]`

مجموعة: عضوية بلا تكرار، على قاموس[ن, منطقي] فتجزئة ن ومساواته هما تجزئة القاموس ومساواته.
