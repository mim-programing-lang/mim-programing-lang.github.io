## Goal

To read a line the user types, and convert it to a number.

## Explanation

- `اقرأ("رسالة")` (read) shows the message, then reads a line the user types. Its result has the type `نص؟` (optional string): a string, or `لاشيء` (nothing) at the end of input. So give it a fallback: `اقرأ("رسالة") والا ""`.
- `حلل(النص, عدد64)` (parse) converts a string to an integer. Its result has the type `!عدد64`, meaning the conversion may fail, so you handle the failure where it happens.

## Common mistakes

`حلل(النص, عدد64)` has the type `!عدد64`, because what the user types may not be a number. So give a fallback value for the failure: `حلل(اقرأ() والا "", عدد64) والا 0`.
