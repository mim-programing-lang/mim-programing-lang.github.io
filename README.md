# موقع لغة ميم

مصدر و الموقع الرسمي للغة البرمجة **ميم**: لغة برمجة عربية الكلمات والاتجاه، تُترجم إلى برامج تنفيذية مستقلة.

**الموقع:** https://meemlang.org/

في الموقع دروس «تعلّم ميم»، والوثائق المرجعية للغة 0.9.0 ومكتبتها القياسية وأخطائها، وتنزيل المجمّع `meem` و«محرر ميم»
للينكس x86_64 (من [الإصدارات](https://github.com/mim-programing-lang/mim-programing-lang.github.io/releases)).

## الرخصة

جميع الحقوق محفوظة إلا ما تمنحه [رخصة ميم](https://meemlang.org/license/).

## هذا المستودع

- الفرع `main`: مصدر الموقع (Astro وStarlight). نص الوثائق المرجعية منسوخ في `handbook/` من الكتاب المرجعي في مستودع المجمّع.
- الفرع `gh-pages`: الموقع المبني، ومنه تقدّمه GitHub Pages.

يُبنى الموقع محلياً، لأن البناء يشغّل المجمّع على أمثلته ويقارن مخرجها بالمسجَّل. الخطوات في [DEPLOY.md](DEPLOY.md).
