# الوحدة `مسارات`

**مولَّدة** من تعليقات الشرح في `stdlib/مسارات.م` (`meem --list-module مسارات --json`). تُستورد بـ`استورد مسارات`
وتُستدعى دوالها `مسارات.دالة(...)`. الشرح الأطول وأمثلته في [../../stdlib.md](../../stdlib.md).

## `ضم`

**التوقيع:** `ضم(اول نص, ثان نص, م مخصص)` ← `نص`

المساران مضمومين بفاصل واحد: «/» بينهما إلا إن انتهى الأول به. والثاني المطلق (يبدأ بـ «/») يُرجَع وحده، والأول
الفارغ يُرجع الثاني. النص من المخصص م إن مُرّر، وإلا من الافتراضي.

المخصص الأخير اختياري: إن تُرك فالافتراضي.

```ميم
استورد مسارات
اطبع(مسارات.ضم("بيانات", "سجل.txt"))
```

```الناتج
بيانات/سجل.txt
```

```ميم
استورد مسارات
اطبع(مسارات.ضم("بيانات/", "سجل.txt"))
```

```الناتج
بيانات/سجل.txt
```

```ميم
استورد مسارات
اطبع(مسارات.ضم("بيانات", "/tmp/ا"))
```

```الناتج
/tmp/ا
```

## `اسم_الملف`

**التوقيع:** `اسم_الملف(مسار نص)` ← `نص`

الجزء الأخير من المسار بعد آخر «/»: المسار كله إن لم يكن فيه فاصل، ونص فارغ إن انتهى بفاصل.

```ميم
استورد مسارات
اطبع(مسارات.اسم_الملف("بيانات/2026/سجل.txt"))
```

```الناتج
سجل.txt
```

```ميم
استورد مسارات
اطبع(مسارات.اسم_الملف("سجل.txt"))
```

```الناتج
سجل.txt
```

```ميم
استورد مسارات
اطبع(طول(اسم_الملف("بيانات/")))
```

```الناتج
0
```

## `المجلد`

**التوقيع:** `المجلد(مسار نص)` ← `نص`

المجلد: ما قبل آخر «/»، ونص فارغ إن لم يكن فيه فاصل، و«/» لمسار في الجذر.

```ميم
استورد مسارات
اطبع(مسارات.المجلد("بيانات/2026/سجل.txt"))
```

```الناتج
بيانات/2026
```

```ميم
استورد مسارات
اطبع(مسارات.المجلد("/سجل.txt"))
```

```الناتج
/
```

```ميم
استورد مسارات
اطبع(طول(المجلد("سجل.txt")))
```

```الناتج
0
```

## `الامتداد`

**التوقيع:** `الامتداد(مسار نص)` ← `نص`

امتداد اسم الملف بنقطته: من آخر «.» في الجزء الأخير، ونص فارغ إن لم يكن فيه نقطة أو كانت النقطة أول حرف فيه
(ملف مخفي مثل .bashrc).

```ميم
استورد مسارات
اطبع(مسارات.الامتداد("صور/رحلة.png"))
```

```الناتج
.png
```

```ميم
استورد مسارات
اطبع(مسارات.الامتداد("نسخة.tar.gz"))
```

```الناتج
.gz
```

```ميم
استورد مسارات
اطبع(طول(الامتداد(".bashrc")))
```

```الناتج
0
```
