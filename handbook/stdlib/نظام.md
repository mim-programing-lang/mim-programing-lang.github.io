# الوحدة `نظام`

**مولَّدة** من تعليقات الشرح في `stdlib/نظام.م` (`meem --list-module نظام --json`). تُستورد بـ`استورد نظام`
وتُستدعى دوالها `نظام.دالة(...)`. الشرح الأطول وأمثلته في [../../stdlib.md](../../stdlib.md).

## `وسائط`

**التوقيع:** `وسائط(م مخصص)` ← `قائمة[نص]`

وسائط سطر الأوامر التي أُعطيت للبرنامج، بلا اسم البرنامج. قائمة فارغة إن لم يُعطَ شيء.
النصوص عروض على الوسائط نفسها (لا تُنسخ ولا تُحرَّر)؛ والقائمة من المخصص م إن مُرّر، وإلا من الافتراضي.
في التشغيل المباشر هي ما بعد «--»:  meem برنامج.م -- ا ب   وفي الملف المبني:  ./برنامج ا ب

المخصص الأخير اختياري: إن تُرك فالافتراضي.

```ميم
استورد نظام
اطبع(طول(وسائط()))
```

```الناتج
0
```

## `بيئة`

**التوقيع:** `بيئة(اسم نص)` ← `نص`

قيمة متغير بيئة، أو لاشيء إن لم يكن معرَّفاً. متغير معرَّف بقيمة فارغة يعطي نصاً فارغاً لا لاشيء.
النص عرض على بيئة العملية نفسها (لا يُنسخ ولا يُحرَّر).

```ميم
استورد نظام
اطبع(نظام.بيئة("متغير_لا_وجود_له_قطعا") == لاشيء)
```

```الناتج
صواب
```

## `انهِ`

**التوقيع:** `انهِ(رمز عدد)` ← `فراغ`

ينهي البرنامج فوراً برمز الخروج المعطى (0 نجاح). الرمز بين 0 و255؛ غير ذلك خطأ تشغيل.
ما طُبع قبلها يُكتب كله. تقرير --debug-mem لا يُطبع بعد إنهاء كهذا.
استعمال: انهِ(2)

```ميم
استورد نظام
اطبع("قبل الإنهاء")
نظام.انهِ(4)
اطبع("لا يُطبع")
```

```خطأ
رمز الخروج: 4
--- stdout ---
قبل الإنهاء
--- stderr ---
```

## `الوقت`

**التوقيع:** `الوقت()` ← `كسر`

الوقت الآن: الثواني منذ بداية 1970 (بتوقيت UTC) بكسورها. ساعة الحائط: قد تُعدَّل فتقفز؛ لقياس مدة استعمل مؤقت.

```ميم
استورد نظام
اطبع(نظام.الوقت() > 1700000000.0)
```

```الناتج
صواب
```

## `مؤقت`

**التوقيع:** `مؤقت()` ← `كسر`

ساعة رتيبة بالثواني لقياس المدد: لا ترجع إلى الوراء ولا تتأثر بتعديل ساعة النظام. قيمتها وحدها لا معنى لها؛
المعنى في الفرق بين قراءتين:  بداية = مؤقت()  ثم  مؤقت() - بداية

```ميم
استورد نظام
اطبع(نظام.مؤقت() >= 0.0)
```

```الناتج
صواب
```

## `التاريخ`

**التوقيع:** `التاريخ()` ← `تاريخ`

التاريخ الآن بتوقيت الجهاز المحلي (المنطقة الزمنية من متغير البيئة TZ، وإلا من إعداد النظام). التقويم الميلادي.

```ميم
استورد نظام
اطبع(نظام.التاريخ().سنة >= 2026)
```

```الناتج
صواب
```

## `نص_التاريخ`

**التوقيع:** `نص_التاريخ(ت تاريخ, م مخصص)` ← `نص`

التاريخ نصاً بصيغة ISO 8601 المحلية بلا منطقة زمنية: السنة-الشهر-اليوم ثم T والساعة:الدقيقة:الثانية، بخانتين لكل
جزء بعد السنة (منذ 0.8.0). النص من المخصص م إن مُرّر، وإلا من الافتراضي.

المخصص الأخير اختياري: إن تُرك فالافتراضي.

```ميم
استورد نظام
اطبع(نظام.نص_التاريخ(تاريخ(2026, 3, 7, 9, 5, 0)))
```

```الناتج
2026-03-07T09:05:00
```

## `نم`

**التوقيع:** `نم(مللي عدد)` ← `فراغ`

ينتظر مدة بالمللي ثانية ثم يكمل البرنامج (منذ 0.8.0). 0 لا ينتظر؛ والمدة السالبة خطأ تشغيل. إشارة تقطع الانتظار لا
تقصّره: يُكمَل ما بقي منه.
استعمال: نم(250)

```ميم
استورد نظام
بداية = نظام.مؤقت()
نظام.نم(50)
اطبع(نظام.مؤقت() - بداية >= 0.05)
```

```الناتج
صواب
```

## `تاريخ` (هيكل)

`سنة عدد`، `شهر عدد`، `يوم عدد`، `ساعة عدد`، `دقيقة عدد`، `ثانية عدد`

التاريخ والوقت المحليان مفصّلين: السنة (2026)، والشهر (1 إلى 12)، واليوم (1 إلى 31)، والساعة (0 إلى 23)،
والدقيقة (0 إلى 59)، والثانية (0 إلى 60، والستون للثانية الكبيسة).

```ميم
استورد نظام
ت = نظام.التاريخ()
اطبع(ت.شهر >= 1 و ت.شهر <= 12, " ", ت.يوم >= 1 و ت.يوم <= 31, " ",
     ت.ساعة < 24, " ", ت.دقيقة < 60)
```
