# الترحيل من 0.13 إلى 0.14

المصدر: [../../../CHANGELOG.md](../../../CHANGELOG.md) (قسم 0.14.0)، والتصميمان [../../design-types-survey.md](../../design-types-survey.md)
بقرارات المالك (2026-11-08) و[../../design-0.11.md](../../design-0.11.md) الجزء الثاني. **قبل 1.0 أفضل تصميم يفوز على التوافق**
([../../deprecation-policy.md](../../deprecation-policy.md))، ولا `--fix` لهذه التغييرات. **لا كلمة جديدة في اللغة.**

## ما يكسر

| كان في 0.13 | صار في 0.14.0 | ما تفعله |
|---|---|---|
| تحذير `E0472` «النص 'ن' يُحجز في كل نداء لـ'ف' ولا يُحرَّر» | **خطأ ترجمة** (رمز 2): البرنامج لا يُشغَّل | `خاتمه حرر(ن)` بعد الحجز، أو `ارجع ن` إن كان للمستدعي. قيس قبل التحويل: لا إنذار كاذب في البرامج المرجعية وأمثلة الكتاب ([../../experiments/e0472-0.14/README.md](../../experiments/e0472-0.14/README.md)) |
| معامل أو متغير أو ثابت أو متغير حلقة باسم `اطبع` أو `طول` أو `اضف` يُقبل ثم ينكسر أول ذكر له بلا قوسين | خطأ نحوي `E0474` عند التعريف | سمّه اسماً آخر (`طول_` أو اسماً يصف ما فيه). حقل الهيكل بهذا الاسم يجوز (`س.طول`) |
| برنامج يستورد `ملفات` ويعرّف دالة باسم `اغلق` أو `اكتب` أو `اكتب_سطر` أو `فرّغ` أو `انتقل` أو `الموضع` أو `الدخل` أو `الخرج` أو `الخطأ` أو `اقرأ_سطر`... | تحذير الحجب `E0271` (خطأ مع `--strict`): الأسماء صارت في الوحدة | سمّ دالتك اسماً آخر (رُحّل `ميزات/خاتمه_والا`: `اغلق` ← `اغلق_مورد`) |
| `E0116` «مؤشر دالة ترجع خطأ غير مدعوم بعد» | مقبول: `داله(عدد64) !عدد64` | لا شيء؛ والغلاف الذي كتبته لتجنّب الخطأ يجوز حذفه |
| `E0155` «لا يُمرَّر إلى C» لهيكل بالقيمة في `خارجي` | `E0477` برسالة الهيكل بالقيمة (لم يتغير أنه خطأ) | أداة تطابق المعرّف: الهيكل بالقيمة صار `E0477` |
| `E0438` لهيكل اختياري `نقطة؟` | مقبول | لا شيء |

## ما يُضاف دون كسر

- **الصفوف**: `داله قسم(ا, ب) (خارج عدد64, باقي عدد64):` ثم `ارجع (ا / ب, ا % ب)`، و`خ, ب = قسم(7, 2)`، و`ن.خارج`،
  و`لكل (س, ص) في مواضع:`. والصف قيمة كاملة ([../language/02-types.md](../language/02-types.md)).
- **قيم أعضاء التعداد وعرضه**: `تعداد حالة: طبيعي16` و`تم = 200` ([../language/12-enums.md](../language/12-enums.md)). التعداد بلا
  قيم كما كان: `عدد64(ل)` موضعه.
- **الحرفيات السداسية والثنائية**: `0xFF8800`، `0b1010`.
- **الهيكل المبهم** `هيكل_سي ملف_c` لمقابض C ([../language/10-ffi.md](../language/10-ffi.md)).
- **القارئ والكاتب والملفات الثنائية** في `ملفات`، و**`نظام.خطأ_النظام()`**، و**النص بالبايت** (ست مدمجات)
  ([../stdlib/README.md](../stdlib/README.md)).
- **تحذير `E0476`**: متغير أو معامل باسم نوع (`عدد64 = 3`، `نقطة = 3` بعد `هيكل نقطة`).
- `حجم_النوع(مصفوفة[كسر64, 3])` وأنواع مركّبة بفاصلة في مدمجات الأنواع.

## أمثلة

```
داله وصف(ع عدد64) عدد64:
    ن = "قيمة " + نص(ع)
    ارجع طول(ن)
```

في 0.13 تحذير `E0472` ويعمل. وفي 0.14.0 خطأ ترجمة. والصحيح:

```
داله وصف(ع عدد64) عدد64:
    ن = "قيمة " + نص(ع)
    خاتمه حرر(ن)
    ارجع طول(ن)
```

```
داله ركب(نوع طبيعي8, طول طبيعي8) طبيعي8:     # 0.14.0: E0474 على 'طول'
```

يصير `داله ركب(نوع طبيعي8, مقدار طبيعي8) طبيعي8:`.

## للأدوات (المحرر والموقع)

- `--list-keywords --json`: في `features` الجديد `number-bases` و`enum-values` و`opaque-c-struct` و`tuples` و`optional-struct`
  و`file-reader-writer` و`binary-files` و`text-bytes` و`system-error` و`fallible-function-pointers`؛ ولا كلمة جديدة في `keywords`.
- `--check --json`: `E0472` صار `severity: "error"`؛ ونوع الصف نصاً في الرسائل بصيغته `(خارج عدد64, باقي عدد64)`.
- التلوين: الحرفيات `0x[0-9A-Fa-f]+` و`0b[01]+` أعداد.
