# الأنواع

**القاعدة.** لكل قيمة نوع يُعرف عند الترجمة. نوع المتغير يثبت من أول إسناد، أو يُكتب بعد اسمه: `س عدد64 = 3`. والأعداد
بأحجامها (منذ 0.12.0، [../../design-numerics.md](../../design-numerics.md)): **التوسيع الآمن ضمني** (`عدد32` إلى `عدد64`،
`بايت` إلى `عدد32`، `كسر32` إلى `كسر64`)، و**التضييق صريح باسم النوع ويُفحص مداه** (`عدد8(ن)`)، و**الخلط بين نوعين لا
يسعهما نوع واحد خطأ ترجمة** (صحيح وكسر: `كسر64(س) / 2`). والحرفية تأخذ النوع المطلوب وتُفحص سعته عند الترجمة
([../../semantics.md](../../semantics.md)).

| النوع | القيمة | ملاحظات |
|---|---|---|
| `عدد64` (و`عدد8` `عدد16` `عدد32`) | صحيح بإشارة بحجمه | نوع الحرفية الصحيحة والأطوال والفهارس؛ التجاوز بعرض النوع خطأ تشغيل (يلتف في `--fast`، وبـ `جمع_ملتف` وأخواتها) |
| `طبيعي8` .. `طبيعي64`، و`بايت` (= `طبيعي8`) | صحيح بلا إشارة | `-` عليه خطأ ترجمة |
| `كسر64` (و`كسر32`) | عشري IEEE-754 بحجمه | نوع الحرفية الكسرية (`2.5`، `1e10`)؛ `1 / 2` صحيحة، `1 / 2.0` كسرية؛ والكسر إلى صحيح بتقريب مسمّى: `رياضيات.بتر/ارضيه/سقف/قرب` |
| `نص` | بايتات UTF-8 لا تتغير | الطول والفهرسة بنقاط الترميز؛ `+` بين نصين فقط؛ لا يكون `لاشيء` (منذ 0.11.0) |
| `رمز` | نقطة ترميز واحدة | `'م'`، وعنصر نص `ن[0]` |
| `منطقي` | `صواب` أو `خطاء` | |
| `لاشيء` | غياب القيمة | يُسند إلى النوع الاختياري `ن؟` وإلى `مؤشر[...]` و`مؤشر_خام` و`نص_سي` وحدها |
| `ن؟` | `ن` أو `لاشيء` (منذ 0.11.0) | `عدد64؟`، `نص؟`، `قائمة[نص]؟`... يُفحص قبل استعماله `ن`: أدناه |
| `قائمة[ن]` | عناصر من نوع واحد، تكبر | **مرجعية**: `ب = ق` اسمان للقائمة نفسها |
| `قاموس[م, ق]` | مفاتيح `نص` أو عدد صحيح بحجمه أو `رمز` أو `منطقي` | مرجعي؛ المرور بترتيب الإدراج |
| `مصفوفة[ن, الطول]` | حجم ثابت | **بالقيمة**: تُنسخ عند الإسناد |
| هيكل | حقول مسمّاة ([06-structs.md](06-structs.md)) | بالقيمة |
| `مؤشر[ن]` و`مؤشر_خام` و`شريحة[ن]` | الطبقة المنخفضة ([09-low-level.md](09-low-level.md)) | |
| `مخصص` | مخصص ذاكرة ([08-memory.md](08-memory.md)) | |
| `داله(أنواع) نوع` | مؤشر دالة ([05-functions.md](05-functions.md)) | منذ 0.7.0 |

الاسمان `عدد` و`كسر` **أُزيلا** (منذ 0.12.0، `E0456`): يُكتب الحجم (`عدد64`، `كسر64` في الغالب). والأحجام كلها أنواع قيم
كاملة: متغير، ومعامل، وإرجاع، وحقل، وعنصر قائمة وقاموس ومصفوفة، ومفتاح قاموس (الصحيحة). وقراءة نص عدداً بـ
`حلل(ن, عدد64) والا 0`.

```ميم
س عدد64 = 7
ك = كسر64(س) / 2       # صحيح وكسر لا يُخلطان بلا تحويل (منذ 0.12.0)
اسماء قائمة[نص] = []
اضف(اسماء, "ميم")
ب = اسماء
اضف(ب, "نون")
م مصفوفة[عدد64, 2] = [1, 2]
ن = م
ن[0] = 9
اطبع(ك, " ", اسماء, " ", م, " ", ن)
```

```الناتج
3.5 [ميم, نون] [1, 2] [9, 2]
```


**النوع الاختياري** (منذ 0.11.0). `ن؟` قيمة من `ن` أو `لاشيء`، ولا تُستعمل كأنها `ن` قبل فحصها:
- `اذا س != لاشيء:` داخل الكتلة `س` من النوع `ن`؛ و`اذا س == لاشيء:` ثم `ارجع`/`توقف`/`تجاوز`/`خطا_قاتل` بعدها كذلك؛
  و`طالما س != لاشيء:` داخل الحلقة. التضييق لمتغير أو معامل، ويلغيه إسناد قيمة قد تكون لاشيء.
- `س والا بديل` قيمتها أو البديل؛ و`س والا:` ثم كتلة آخر سطر فيها البديل أو قفز.
- `اطبع(س)` تطبع القيمة أو `لاشيء`. وحقل `ن؟` في هيكل بلا قيمة يبدأ `لاشيء`.
- **`==` بين قيمتين اختياريتين خطأ ترجمة** (`E0537` منذ 0.17.3): ضيّق النوع أولاً (`اذا س != لاشيء:`)، أو قارن
  بعد البديل (`(س والا 0) == (ص والا 0)`). والمقارنة بـ`لاشيء` نفسها مدعومة.
- ما يرجع غياباً في المكتبة: `بحث` (`عدد64؟`)، و`اقرأ()` (`نص؟`: لاشيء عند نهاية الإدخال)، و`نظام.بيئة` و`من_نص_سي` (`نص؟`).
- الهيكل والصف يكونان اختياريين منذ 0.14.0 (`نقطة؟`)؛ والمصفوفة والشريحة لا. والمؤشرات تقبل `لاشيء` بلا `؟` (كمؤشرات C).

```ميم
داله اول_زوجي(ق قائمة[عدد64]) عدد64؟:
    لكل ن في ق:
        اذا ن % 2 == 0:
            ارجع ن
    ارجع لاشيء
س = اول_زوجي([1, 6, 3])
اذا س != لاشيء:
    اطبع(س * 10)
اطبع(اول_زوجي([1]), " ", اول_زوجي([1]) والا -1, " ", بحث("ميم", "ي"))
```

```الناتج
60
لاشيء -1 1
```

**الهيكل الاختياري** (منذ 0.14.0): دالة ترجع هيكلاً أو لاشيء، والفحص كبقية `ن؟`.

```ميم
هيكل نقطة:
    س عدد64
    ص عدد64
داله اول_موجبة(ق قائمة[نقطة]) نقطة؟:
    لكل ن في ق:
        اذا ن.س > 0:
            ارجع ن
    ارجع لاشيء
نقاط قائمة[نقطة] = [نقطة(-1, 2), نقطة(3, 4)]
م = اول_موجبة(نقاط)
اذا م != لاشيء:
    اطبع(م.ص)
اطبع(اول_موجبة([نقطة(-5, 0)]))
حرر(نقاط)
```

```الناتج
4
لاشيء
```


**الصف والإرجاع المتعدد** (منذ 0.14.0، [../../design-types-survey.md](../../design-types-survey.md) القسم 3). الصف هيكل بلا اسم بأسماء حقوله وأنواعها: `(خارج عدد64, باقي عدد64)`، حقلان فأكثر. يُكتب نوعاً حيث يُكتب نوع (إرجاع، ومتغير `ز (س عدد64, ص عدد64) = (3, 4)`، ومعامل، وعنصر قائمة وقاموس)، وقيمته `(ا, ب)` تأخذ نوعها من موضعها. ويُفكّ `خ, ب = ف()` (و`_` لحقل لا تريده)، وفي `لكل (س, ص) في ...`، ويُقرأ حقله `ن.خارج`، ويُطبع `(خارج: 3, باقي: 1)`. صفّان بالأسماء والأنواع نفسها بالترتيب نفسه نوع واحد. ومع `!ن`: `داله ف() !(ا عدد64, ب عدد64)` و`خ, ب = جرّب ف()` و`ف() والا (0, 0)`.

```ميم
داله قسم(ا عدد64, ب عدد64) (خارج عدد64, باقي عدد64):
    ارجع (ا / ب, ا % ب)
خ, ب = قسم(17, 5)
ن = قسم(9, 4)
اطبع(خ, " ", ب, " ", ن, " ", ن.خارج)
مواضع قائمة[(س كسر64, ص كسر64)] = [(1.0, 2.0), (3.5, 0.5)]
لكل (س, ص) في مواضع:
    اطبع(س + ص)
حرر(مواضع)
```

```الناتج
3 2 (خارج: 2, باقي: 1) 2
3.0
4.0
```


**النوع الجديد القوي نمطاً** (بلا ميزة جديدة): هيكل بحقل واحد يجعل المتر والثانية نوعين لا يختلطان، والشيفرة المولَّدة له هي شيفرة `كسر64` نفسها ([../../design-types-survey.md](../../design-types-survey.md)، التجربة 7).

```ميم
هيكل متر:
    ق كسر64
هيكل ثانية:
    ق كسر64
داله سرعة(م متر, ث ثانية) كسر64:
    ارجع م.ق / ث.ق
اطبع(سرعة(متر(100.0), ثانية(8.0)))
```

```الناتج
12.5
```



**النص بالبايت** (منذ 0.14.0): `طول` و`جزء` و`بحث` و`ن[ف]` بالحرف للنص قيمةً؛ و`طول_بايت` و`بايت_عند` و`جزء_بايت` (عرض، والحدّ على حدّ حرف UTF-8) و`بحث_بايت` بالبايت للنص بيانات، و`بايتات_نص` و`نص_من_بايتات` بين النص و`شريحة[بايت]`. والأعداد تُكتب سداسيةً `0xFF` وثنائيةً `0b1010` أيضاً.

```ميم
ن = "ميم: 3"
اطبع(طول(ن), " ", طول_بايت(ن), " ", بايت_عند(ن, 0), " ", بحث_بايت(ن, ":"), " [", جزء_بايت(ن, 0, 6), "]")
ش = بايتات_نص(ن)
اطبع(طول(ش), " ", نص_من_بايتات(ش) والا "؟")
حرر(ش)
اطبع(0xFF, " ", 0b1010, " ", 0x10 | 0b1)
```

```الناتج
6 9 217 6 [ميم]
9 ميم: 3
255 10 17
```


**الأنواع المعمَّمة** (منذ 0.15.0 للدوال، و0.16.0 للهياكل والتعدادات) والسمات (منذ 0.17.0) في
[14-generics.md](14-generics.md): `هيكل زوج[ا, ب]:` و`تعداد نتيجة[ن]:` و`داله اكبر[ن](...)` و`سمة` و`يحقق`.
و**الاتحاد الموسوم** (التعداد بحمولة، منذ 0.15.0) والتعداد (أعضاء بلا قيم) في [12-enums.md](12-enums.md).

**القيود المعروفة.** المعامل من صنف حاوية بلا نوع عناصر (`ق قائمة`) يبقى اختصاراً للمعمَّم لا طريقة ثانية
([05-functions.md](05-functions.md)).
مقارنة عدد بكسر فوق 2^53 تقريبية. وفهرسة النص بالحرف (`ن[ف]`) كلفتها خطية في طوله: النص UTF-8، والوصول إلى الحرف رقم ف
يعدّ من أوله؛ للمرور على النص كله `لكل ح في ن` ([../../strings-and-print.md](../../strings-and-print.md)).

**أخطاء محتملة.**

```ميم
س = 1
س = "نص"
```

```خطأ
     | ^
```
