**القاعدة (منذ 0.7.0).** لا عدّ مراجع ولا جامع قمامة. كل نص يُبنى وكل قائمة وقاموس يُحجز من **مخصص**: الافتراضي إن لم
يُذكر غيره. ما لا يُحرَّر يعود للنظام عند خروج البرنامج. التفصيل في `memory.md` <small>(وثيقة في مستودع المجمّع)</small>
و`allocators.md` <small>(وثيقة في مستودع المجمّع)</small>.

| الأداة | ما تفعله |
|---|---|
| `حرر(س[, م])` | يعيد نصاً أو قائمة أو قاموساً أو خانة أو شريحة الآن، ويجعل `س` لاشيء. لا يتبع ما في الحاوية |
| `خاتمه جملة` | يؤجّل الجملة إلى الخروج من الكتلة (ومنه `ارجع` و`توقف` و`تجاوز`)، بعكس الترتيب |
| `ساحة(الاصل)` | مخصص يجمع ما يُحجز منه، و`اعد(ساحه)` تعيده كله |
| `كاشف(الاصل)` | مخصص يبلّغ عمّا لم يُحرَّر منه عند `اعد` أو النهاية |
| `مخزن_ثابت(شريحة)` | مخصص فوق ذاكرة ثابتة؛ امتلاؤه خطأ تشغيل |
| `قائمة_من([...], م)` و`نسخ(س, م)` | تبني الحاوية في مخصص |
| آخر وسيط `مخصص` في المدمجات والدوال | اختياري: ما تبنيه يُحجز منه |
| `--debug-mem` | الافتراضي كاشف: التحرير المزدوج والاستعمال بعد التحرير أخطاء تشغيل، وتقرير عند النهاية |
| `بلا_افتراضي` (ترويسة) و`--no-default-allocator` | كل حجز يذكر مخصصه صراحة |

<HBExample id="language/08-memory.md#1" />

**القيود المعروفة.** النص المؤقت في حلقة طويلة يبقى حتى الخروج إن لم يُحرَّر (ذروة الذاكرة؛ القياس في
`v1-readiness.md` <small>(وثيقة في مستودع المجمّع)</small>). الاستعمال بعد `حرر` للنص والقائمة لا يُكشف إلا بأثره.
الحجز من ساحة أُعيدت سلوك غير معرَّف خارج `--debug-mem`.
