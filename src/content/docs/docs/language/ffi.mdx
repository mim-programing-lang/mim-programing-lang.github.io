**القاعدة.** `خارجي "مكتبة" داله الاسم(المعامل نوع_C, ...) نوع_C باسم "اسم_C"` في المستوى الأعلى يصرّح بدالة من مكتبة C؛
بلا مكتبة فهي من مكتبة C نفسها. الأنواع في التوقيع أنواع C (جدولها في [المفردات](/docs/language/lexicon/)). الرمز يُفحص قبل
التشغيل: مفقود خطأ ترجمة برمز 2. `--no-ffi` يمنع `خارجي` في برنامج المستخدم (لا في المكتبة القياسية). التفصيل في
`stdlib-design.md` <small>(وثيقة في مستودع المجمّع)</small> و`low-level.md` <small>(وثيقة في مستودع المجمّع)</small>.

- `نص` يُمرَّر منتهياً بصفر؛ ونص ترجعه C يُنسخ (`نص_مملوك`: يُنسخ ثم يُحرَّر الأصل بـ`free`). و`نص` لا يكون NULL: C ترجعه
  NULL خطأ تشغيل (`E0443`)؛ و`نص؟` (منذ 0.11.0، بدل `نص_او_لاشيء`) يقبل NULL معاملاً وإرجاعاً، ويكون لاشيء.
- الأعداد بأحجامها: القيمة خارج مدى `عدد32` خطأ تشغيل عند الاستدعاء.
- منذ 0.7.0: `هيكل_سي` (تخطيط C، `حجم_النوع` يطابق `sizeof`) و`مؤشر[هيكل_سي]` في التوقيع، و`نص_سي` (`char *`
  بلا نسخ، مع `نص_سي(ن[, م])` و`من_نص_سي(خ)`)، ودالة ميم تُمرَّر باسمها إلى C (استدعاء عكسي).
- **الخيوط عبر `خارجي`** (`pthread_create`، `thrd_create`) تعمل مباشرةً ومبنيةً (منذ 0.12.0)، لكن حالة وقت التشغيل غير آمنة
  للخيوط والسباق سلوك غير معرَّف: ما يجوز وما لا يجوز في `memory-safety.md` <small>(وثيقة في مستودع المجمّع)</small> القسم 6.

<HBExample id="language/10-ffi.md#1" />

**المقبض المبهم** (منذ 0.14.0): `هيكل_سي الاسم` بلا نقطتين ولا حقول نوع C مبهم (كـ `struct FILE;` في C)، يُستعمل `مؤشر[الاسم]` وحده، فمقبض ملف ومقبض نافذة نوعان لا يختلطان؛ وبالقيمة أو `محتوى` أو `حجم_النوع` خطأ `E0478`.

<HBExample id="language/10-ffi.md#2" />

**الهيكل بالقيمة لا يُمرَّر إلى C** (منذ 0.14.0 خطأ برسالته `E0477`، لا نتيجة خاطئة صامتة): قواعد ABI لتمرير الهيكل بالقيمة لا يكتبها المجمّع بعد؛ مرّر مؤشراً، أو اكتب غلافاً صغيراً في C.

<HBExample id="language/10-ffi.md#3" />

**القيود المعروفة.** لا دوال متغيرة عدد الوسائط (`printf`). القوائم والقواميس والهياكل والصفوف بالقيمة لا تُمرَّر. و`long` في C يقابل `عدد64` في لينكس x86_64 وحده (وفي ويندوز `long` 4 بايتات: `عدد32`). دالة ميم إلى
C تُمرَّر باسمها لا بمتغير. C التي تحتفظ بمؤشر نص بعد رجوعها مسؤولية كاتب التصريح.
