## Goal

To import a standard module and use its functions.

## Explanation

- A **module** is a `.م` file you import into your program. The **standard library** is the set of modules that come with the compiler.
- Write `استورد رياضيات` (import math) at the top of the file, then call its functions like this: `رياضيات.جذر(81.0)`, that is, the module name, a dot, then the function name.
