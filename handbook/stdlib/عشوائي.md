# الوحدة `عشوائي`

**مولَّدة** من تعليقات الشرح في `stdlib/عشوائي.م` (`meem --list-module عشوائي --json`). تُستورد بـ`استورد عشوائي`
وتُستدعى دوالها `عشوائي.دالة(...)`. الشرح الأطول وأمثلته في [../../stdlib.md](../../stdlib.md).

## `بذرة`

**التوقيع:** `بذرة(ن عدد)` ← `فراغ`

يثبّت بذرة المولّد: ما يُسحب بعدها تسلسل واحد معروف لهذه البذرة. تُستدعى مرة في أول البرنامج لنتائج تتكرر.
استعمال: بذرة(42)

```ميم
استورد عشوائي
عشوائي.بذرة(42)
ا = عشوائي.صحيح(1, 100)
عشوائي.بذرة(42)
ب = عشوائي.صحيح(1, 100)
اطبع(ا == ب)
```

```الناتج
صواب
```

## `صحيح`

**التوقيع:** `صحيح(من عدد, الى عدد)` ← `عدد`

عدد صحيح عشوائي بين «من» و«الى»، **والطرفان منه**، وكل قيمة باحتمال واحد. «من» أكبر من «الى»: خطأ تشغيل.
(بخلاف مدى(من, الى) التي لا تشمل نهايتها: لفهرس عشوائي في قائمة اكتب صحيح(0, طول(ق) - 1).)

```ميم
استورد عشوائي
اطبع(عشوائي.صحيح(5, 5))
```

```الناتج
5
```

## `كسر`

**التوقيع:** `كسر()` ← `كسر`

كسر عشوائي أكبر من أو يساوي 0 وأصغر من 1، بدقة الكسر كلها (53 بتاً).

```ميم
استورد عشوائي
اطبع(عشوائي.كسر() < 1.0)
```
