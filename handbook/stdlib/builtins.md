# المدمجات

**مولَّدة** من `builtin_funcs.BUILTINS` بـ`scripts/gen_handbook.py`؛ لا تُحرَّر باليد. المدمجة لا تحتاج استيراداً.
كل مثال يُشغَّل في `tests/test_docs.py`. الأخطاء المذكورة لكل مدمجة هي رسائل مصدرها (الفهرس:
[../errors/catalog.md](../errors/catalog.md)).

## `احجز`

**الصيغة:** `احجز(نوع, عدد[, المخصص])`

يحجز كتلة من عناصر متجاورة مصفَّرة ويرجع شريحة عليها (فهرستها بفحص حدود)؛ من المخصص إن مُرّر وإلا من الافتراضي، وتُحرَّر بـ حرر(الشريحة[, المخصص])

```ميم
ش = احجز(عدد32, 3)
ش[0] = 7
اطبع(ش, " ", طول(ش))
حرر(ش)
```

```الناتج
[7, 0, 0] 3
```

## `احجز_خام`

**الصيغة:** `احجز_خام(نوع, عدد[, المخصص])`

يحجز كتلة ويرجع مؤشراً إلى أولها، فهرسته بلا فحص حدود (داخل خطر)؛ تُحرَّر بـ حرر(المؤشر[, المخصص])

```ميم
خطر:
    م = احجز_خام(عدد64, 2)
    م[1] = 5
    اطبع(م[0] + م[1])
    حرر(م)
```

```الناتج
5
```

## `احذف`

**الصيغة:** `احذف(القاموس, المفتاح)   أو   احذف(القائمة, الموضع)`

يحذف مفتاحاً من القاموس ويرجع قيمته (منذ 0.13.0؛ خطأ تشغيل إن لم يكن موجوداً، والقيمة لك: حرّرها إن كانت نصاً أو حاوية لا تحتاجها)، أو العنصر رقم الموضع من القائمة (خارجها خطأ تشغيل)

```ميم
ق = {"ا": 1, "ب": 2}
احذف(ق, "ا")
ل = [10, 20, 30]
احذف(ل, 1)
اطبع(ق, " ", ل)
```

```الناتج
{ب: 2} [10, 30]
```

## `ادرج`

**الصيغة:** `ادرج(القائمة, الموضع, القيمة)`

يدرج القيمة قبل العنصر رقم الموضع (من 0 إلى طول القائمة؛ الطول يعني آخرها كـ اضف)

**أخطاؤها:**

- موضع الإدراج %lld خارج القائمة (من 0 إلى %lld)

```ميم
ق = [1, 3]
ادرج(ق, 1, 2)
ادرج(ق, 3, 4)
اطبع(ق)
```

```الناتج
[1, 2, 3, 4]
```

## `استبدال`

**الصيغة:** `استبدال(النص, القديم, الجديد[, المخصص])`

يستبدل كل ظهور للنص القديم بالجديد

المخصص الأخير اختياري (يُعرف بنوعه): ما تبنيه يُحجز منه، وإلا من الافتراضي.

**أخطاؤها:**

- النص المطلوب استبداله في 'استبدال' لا يمكن أن يكون فارغاً

```ميم
اطبع(استبدال("قطة وقطة", "قطة", "كلب"))
```

```الناتج
كلب وكلب
```

## `اسم_الخطأ`

**الصيغة:** `اسم_الخطأ(خ)`

اسم الخطأ وحده نصاً (بلا رسالته وسببه)، بلا حجز: لمفتاح قاموس أو مقارنة

(لا مثال بعد)

## `اضف`

**الصيغة:** `اضف(القائمة, القيمة)`

يضيف قيمة إلى نهاية القائمة

**أخطاؤها:**

- 'اضف' تعمل مع القوائم فقط لكن وُجد النوع '…'
- 'اضف' تعمل مع القوائم فقط لكن … من النوع '…'
- لا يمكن إضافة عنصر إلى المصفوفة … لأن حجمها ثابت
- لا يمكن استخدام 'اضف' مع القاموس …

```ميم
ق = [1]
اضف(ق, 2)
اطبع(ق)
```

```الناتج
[1, 2]
```

## `اطبع`

**الصيغة:** `اطبع(قيمة, قيمة, ...)`

يطبع القيم متتالية بلا فاصل ثم سطراً جديداً

```ميم
اطبع("س = ", 3, " ", [1, 2], " ", صواب)
```

```الناتج
س = 3 [1, 2] صواب
```

## `اعد`

**الصيغة:** `اعد(المخصص)`

ينهي ساحة (يعيد كل كتلها إلى أصلها) أو كاشفاً (يبلّغ عمّا لم يُحرَّر)؛ لا يُستعمل المخصص بعدها

**أخطاؤها:**

- المخصص أُعيد بـ 'اعد' من قبل
- النظام والافتراضي لا يُعادان: 'اعد' للساحة والكاشف

```ميم
ساحه = ساحة(الافتراضي)
ق = قائمة_من([1, 2], ساحه)
اطبع(طول(ق))
اعد(ساحه)
```

```الناتج
2
```

## `اعكس`

**الصيغة:** `اعكس(القائمة)`

يعكس ترتيب عناصر القائمة في مكانها

```ميم
ق = [1, 2, 3]
اعكس(ق)
اطبع(ق)
```

```الناتج

```

## `اقرأ`

**الصيغة:** `اقرأ()   أو   اقرأ("رسالة", قيمة, ...)`

صيغ أخرى للاسم: `اقرا`

يقرأ سطراً من إدخال المستخدم (بعد عرض رسالة اختيارية)؛ لاشيء عند نهاية الإدخال (نص؟ منذ 0.11.0، كان نصاً فارغاً لا يُفرَّق من سطر فارغ)

المخصص الأخير اختياري (يُعرف بنوعه): ما تبنيه يُحجز منه، وإلا من الافتراضي.

**أخطاؤها:**

- الوسيط رقم … لـ '…' من النوع '…' ولا يمكن وضعه في رسالة

```ميم
س = اقرأ()
اطبع("[", س, "]")
```

```الناتج
[لاشيء]
```

## `انتهى_الدخل`

**الصيغة:** `انتهى_الدخل()`

هل انتهى الإدخال القياسي (فلا سطر آخر تقرؤه اقرأ)؟

```ميم
اسطر = 0
طالما صواب:
    اذا انتهى_الدخل():
        توقف
    س = اقرأ()
    اسطر += 1
اطبع("اسطر: ", اسطر)
```

```الناتج
اسطر: 0
```

## `بايت_عند`

**الصيغة:** `بايت_عند(النص, الموضع)`

البايت رقم الموضع (من 0) في النص، عدداً من 0 إلى 255؛ خارج النص خطأ تشغيل

**أخطاؤها:**

- الفهرس %lld خارج الحدود (الحجم %lld)

```ميم
اطبع(بايت_عند("abc", 1))
```

```الناتج
98
```

## `بايتات_نص`

**الصيغة:** `بايتات_نص(النص[, المخصص])`

نسخة من بايتات النص شريحةً شريحة[بايت] (للكتابة الثنائية والشبكة وC)؛ تُحرَّر بـ حرر(ش[, المخصص])

المخصص الأخير اختياري (يُعرف بنوعه): ما تبنيه يُحجز منه، وإلا من الافتراضي.

```ميم
ش = بايتات_نص("ab")
اطبع(ش)
حرر(ش)
```

```الناتج
[97, 98]
```

## `بحث`

**الصيغة:** `بحث(النص, الجزء)   أو   بحث(القائمة, القيمة)`

موضع أول ظهور للجزء في النص (بعدد الأحرف، من 0)، أو فهرس أول عنصر يساوي القيمة في القائمة؛ لاشيء إن لم يوجد (عدد؟ منذ 0.11.0، كان -1)

```ميم
اطبع(بحث("مرحبا بالعالم", "بال"), " ", بحث([5, 7, 9], 9), " ", بحث([1], 4))
```

```الناتج
6 2 لاشيء
```

موضع أول ظهور للجزء في النص بالبايت (من الموضع من إن مُرّر)، أو لاشيء إن لم يوجد

يقسّم النص عند كل ظهور للفاصل إلى قائمة نصوص

المخصص الأخير اختياري (يُعرف بنوعه): ما تبنيه يُحجز منه، وإلا من الافتراضي.

**أخطاؤها:**

- فاصل 'تقسيم' لا يمكن أن يكون نصاً فارغاً

```الناتج
[ا, ب, , ج]
```

## `جديد`

**الصيغة:** `جديد(القيمة[, المخصص])`

يحجز خانة جديدة على الكومة فيها القيمة ويرجع مؤشراً إليها (من المخصص إن مُرّر، وإلا من الافتراضي)

```ميم
م = جديد(41)
اطبع(محتوى(م) + 1)
حرر(م)
```

```الناتج
42
```

## `جزء`

**الصيغة:** `جزء(النص, البداية, النهاية)   أو   جزء(النص, البداية)`

جزء من النص (بعدد الأحرف) عرضاً على بايتاته نفسها، بلا حجز ولا نسخ (0.7.0)؛ يعيش ما عاش النص الأصل، ولا يُحرَّر

```ميم
ن = "مرحبا بالعالم"
اطبع(جزء(ن, 6), "|", جزء(ن, 0, 5))
```

```الناتج
بالعالم|مرحبا
```

## `جزء_بايت`

**الصيغة:** `جزء_بايت(النص, البداية, النهاية)   أو   جزء_بايت(النص, البداية)`

جزء من النص بمواضع البايت، عرضاً بلا حجز كـ جزء؛ والحدّان على حدّ حرف UTF-8 وإلا خطأ تشغيل، فالنص يبقى صالحاً. الخارج عن النص يُقصّ إلى طرفيه

```ميم
اطبع(جزء_بايت("ميم: 3", 0, 6))
```

```الناتج
ميم
```

## `جمع_ملتف`

**الصيغة:** `جمع_ملتف(ا, ب)`

جمع صحيحين بالتفاف معرَّف عند التجاوز (المتمم الثنائي بعرض نوعهما)، بلا خطأ تشغيل

```ميم
اطبع(جمع_ملتف(عدد8(127), عدد8(1)), " ", جمع_ملتف(طبيعي8(250), 10))
```

```الناتج
-128 4
```

**الصيغة:** `حاول_احجز(نوع, عدد[, المخصص])`

```ميم
ش = حاول_احجز(عدد64, 4) والا خ:
    خطا_قاتل("لا ذاكرة")
اطبع(طول(ش))

```

```الناتج
4
```

## `حرر`

**الصيغة:** `حرر(المؤشر[, المخصص])`

يحرر الخانة التي يشير إليها المؤشر ويجعل المؤشر لاشيء (بالمخصص الذي حجزها؛ المتروك الافتراضي)

**أخطاؤها:**

- لا يمكن تحرير الثابت '…': 'حرر' يجعل المؤشر لاشيء وهذا تعديل للثابت

```ميم
م = جديد(1)
حرر(م)
اطبع(م == لاشيء)
```

```الناتج
صواب
```

## `حلل`

**الصيغة:** `حلل(النص, النوع)`

يقرأ النص عدداً من النوع المكتوب (عدد64، طبيعي8، كسر64...): !النوع، وخطأ.صيغة_خاطئة لنص ليس عدداً، وخطأ.خارج_المدى لعدد لا يتسع فيه

**أخطاؤها:**

- 'حلل' تقرأ عدداً من الأنواع العددية لا '…'
- 'حلل' تقرأ نصاً لا '…'

```ميم
اطبع((حلل("42", عدد64) والا 0) + 1, " ", حلل("س", عدد64) والا -1, " ", حلل("300", بايت) والا 0, " ", حلل("2.5", كسر64) والا 0.0)
```

```الناتج
43 -1 0 2.5
```

## `حوّل`

**الصيغة:** `حوّل(قيمة, نوع)`

صيغ أخرى للاسم: `حول`

يعيد تفسير مؤشر أو شريحة بنوع آخر: مؤشر[ا] إلى مؤشر[ب] أو مؤشر_خام، شريحة[ا] إلى شريحة[ب] (داخل خطر)

**أخطاؤها:**

- حوّل: حجم الشريحة %lld بايتاً لا ينقسم على حجم العنصر الجديد %lld
- لا تحويل من '…' إلى '…'

```ميم
خطر:
    م = احجز_خام(طبيعي8, 8)
    م[0] = 1
    ع = حوّل(م, مؤشر[عدد64])
    اطبع(ع[0])
    حرر(م)
```

```الناتج
1
```

## `خطا_قاتل`

**الصيغة:** `خطا_قاتل(الرسالة)`

ينهي البرنامج بخطأ تشغيل (رمز الخروج 3) برسالته: لخطأ المبرمج الذي لا يُكمَل بعده

```ميم
اطبع("قبل")
خطا_قاتل("توقف هنا")
```

```خطأ
رمز الخروج: 3
--- stdout ---
قبل
--- stderr ---
[خطأ تشغيل] سطر 2:1 - توقف هنا
  خطا_قاتل("توقف هنا")
```

## `دمج_نصوص`

**الصيغة:** `دمج_نصوص(قطعة, قطعة, ...[, المخصص])`

يبني نصاً جديداً من قيم مفردة (نصوص وأعداد وكسور ومنطقي ورموز) كما يدمجها '+'، من المخصص إن مُرّر وإلا من الافتراضي (0.7.0)

المخصص الأخير اختياري (يُعرف بنوعه): ما تبنيه يُحجز منه، وإلا من الافتراضي.

**أخطاؤها:**

- الوسيط رقم … لـ 'دمج_نصوص' من النوع '…' ولا يُدمج في نص

```ميم
ن = دمج_نصوص("س = ", 3, "، ص = ", 4.5)
اطبع(ن)
```

```الناتج
س = 3، ص = 4.5
```

## `رتب`

**الصيغة:** `رتب(القائمة)`

يرتّب قائمة أعداد أو كسور أو نصوص تصاعدياً في مكانها. الكسر ليس_عدداً في الآخر؛ النصوص بترتيب نقاط الترميز (لا ترتيب معجمي عربي)

**أخطاؤها:**

- 'رتب' على قائمة عناصرها '…' غير مدعومة

```ميم
ق = [3, 1, 2]
رتب(ق)
ن = ["ب", "ا"]
رتب(ن)
اطبع(ق, " ", ن)
```

```الناتج
[1, 2, 3] [ا, ب]
```

## `رتب_ب`

**الصيغة:** `رتب_ب(القائمة, قبل)`

يرتّب القائمة في مكانها بمقارن: قبل(ا, ب) صواب إن كان ا قبل ب. ترتيب مستقر (المتساويان يبقيان بترتيبهما)، ولأي نوع عناصر (منذ 0.8.0)

**أخطاؤها:**

- مقارن 'رتب_ب' من النوع '…' لكن وُجد '…'

```ميم
هيكل شخص:
    اسم نص
    عمر عدد64
داله اصغر(ا شخص, ب شخص) منطقي:
    ارجع ا.عمر < ب.عمر
ن = [شخص("علي", 30), شخص("منى", 25), شخص("سارة", 30)]
رتب_ب(ن, اصغر)
لكل ش في ن:
    اطبع(ش.اسم, " ", ش.عمر)
```

```الناتج
منى 25
علي 30
سارة 30
```

## `رسالة`

**الصيغة:** `رسالة(خ[, المخصص])`

نسخة من رسالة الخطأ (ما بعد «مع» عند إنشائه) نصاً من المخصص، أو لاشيء إن لم تكن له رسالة أو كُتب فوق سياقه (منذ 0.12.0؛ كانت نصاً فارغاً). ورسالة «مع ""» الفارغة لاشيء كذلك

المخصص الأخير اختياري (يُعرف بنوعه): ما تبنيه يُحجز منه، وإلا من الافتراضي.

(لا مثال بعد)

## `رقم_النظام`

**الصيغة:** `رقم_النظام(خ)`

رقم خطأ النظام (errno) المرفق بالخطأ، أو 0

(لا مثال بعد)

## `ساحة`

**الصيغة:** `ساحة(الاصل)`

مخصص يأخذ كتلاً من أصله ويحجز منها بالتتابع؛ اعد(س) يعيدها كلها دفعة واحدة (حرر وحده لا يعيد شيئاً)

```ميم
ساحه = ساحة(الافتراضي)
خاتمه اعد(ساحه)
ق = تقسيم("ا ب ج", " ", ساحه)
اطبع(ق)
```

```الناتج
[ا, ب, ج]
```

## `شريحة`

**الصيغة:** `شريحة(مؤشر, الطول)`

شريحة فوق كتلة: مؤشر وطول، لا تملك الكتلة؛ فهرستها بفحص حدود (تُنشأ داخل خطر)

**أخطاؤها:**

- 'شريحة' تأخذ مؤشراً إلى كتلة لكن وُجد '…'
- الشريحة أطول من كتلتها: طولها %lld عنصراً والكتلة %lld بايتاً
- طول الشريحة %lld سالب
- طول الشريحة عدد صحيح لا '…'

```ميم
خطر:
    م = احجز_خام(عدد64, 3)
    ش = شريحة(م, 3)
    ش[2] = 9
    اطبع(ش)
    حرر(م)
```

```الناتج
[0, 0, 9]
```

## `شريحة_خام`

**الصيغة:** `شريحة_خام(مؤشر_خام, نوع, الطول)`

شريحة فوق ذاكرة جاءت من مكتبة C (داخل خطر؛ الطول على مسؤولية كاتبها)

**أخطاؤها:**

- 'شريحة_خام' تأخذ مؤشر_خام لكن وُجد '…'
- شريحة_خام: طول سالب، أو مؤشر لاشيء بطول %lld

```ميم
خارجي داله نسخة(ن نص) مؤشر_خام باسم "strdup"
خارجي داله احرر_c(م مؤشر_خام) فراغ باسم "free"
خام = نسخة("abc")
خطر:
    ش = شريحة_خام(خام, بايت, 3)
    اطبع(ش)
احرر_c(خام)
```

```الناتج
[97, 98, 99]
```

## `ينتهي_بـ`

**الصيغة:** `ينتهي_بـ(النص, اللاحقة)`

هل ينتهي النص باللاحقة؟ (اللاحقة الفارغة: صواب)

```ميم
اطبع(ينتهي_بـ("ملف.txt", ".txt"), " ", ينتهي_بـ("ملف.txt", ".م"))
```

```الناتج
صواب خطاء
```

## `يوجد`

**الصيغة:** `يوجد(القاموس, المفتاح)`

هل المفتاح موجود في القاموس؟

```ميم
ق = {"ا": 1}
اطبع(يوجد(ق, "ا"), " ", يوجد(ق, "ب"))
```

```الناتج
صواب خطاء
```
