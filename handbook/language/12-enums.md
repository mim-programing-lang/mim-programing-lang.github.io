# التعداد

**القاعدة (منذ 0.7.0).** `تعداد الاسم:` في المستوى الأعلى، ثم عضو في كل سطر. الاسم نوع، والعضو `الاسم.العضو`، ورقمه موضعه
من 0. القرار وتفصيله في [../../enums.md](../../enums.md).

| العملية | ما تفعله |
|---|---|
| `==` و`!=` | بين قيمتين من التعداد نفسه |
| `اطبع(ل)` و`نص(ل)` | اسم العضو |
| `عدد64(ل)` | رقم العضو |
| `لون(ن)` | العضو برقمه: `!لون`، وخارج الأعضاء `خطأ.خارج_المدى` |
| `حالات ل:` | بلا `حاله _` يجب أن يُذكر كل عضو (خطأ ترجمة يسمّي الناقص)؛ ودالة كل فروع `حالات` المكتملة فيها `ارجع` لا تُحذَّر |
| `لكل ل في لون:` | الأعضاء بترتيب تعريفها (منذ 0.8.0) |
| مفتاح قاموس | `قاموس[لون, عدد64]` و`{لون.احمر: 1}` (منذ 0.8.0) |
| في وحدة مستوردة | `لون` وحده إن لم يتكرر في وحدتين، و`وحدة.لون.احمر` دائماً؛ و`خاص تعداد` لا يُصدَّر (منذ 0.8.0) |

```ميم
تعداد اشارة:
    احمر
    اصفر
    اخضر

داله التالية(ا اشارة) اشارة:
    حالات ا:
        حاله اشارة.احمر:
            ارجع اشارة.اخضر
        حاله اشارة.اخضر:
            ارجع اشارة.اصفر
        حاله اشارة.اصفر:
            ارجع اشارة.احمر

ا = اشارة.احمر
لكل خطوة في مدى(0, 4):
    اطبع(خطوة, ": ", ا, " (", عدد64(ا), ")")
    ا = التالية(ا)
اطبع(اشارة(1) والا اشارة.احمر, " ", اشارة(9) والا اشارة.احمر)
```

```الناتج
0: احمر (0)
1: اخضر (2)
2: اصفر (1)
3: احمر (0)
اصفر احمر
```

`لكل` على التعداد ومفتاح القاموس منه (منذ 0.8.0):

```ميم
تعداد يوم:
    سبت
    احد
    اثنين

ساعات قاموس[يوم, عدد64] = {}
لكل ي في يوم:
    ساعات[ي] = 8 - عدد64(ي)
اطبع(ساعات, " ", ساعات[يوم.احد])
```

```الناتج
{سبت: 8, احد: 7, اثنين: 6} 7
```



**قيم الأعضاء وعرض التعداد** (منذ 0.14.0). `تعداد الاسم: طبيعي8` يحدد عرضه (نوع صحيح بحجمه؛ بلا عرض `عدد32`)، و`العضو = 5` قيمته (عدد صحيح حرفي، سالب أو سداسي)؛ والعضو بلا قيمة موضعه، أو السابق + 1 بعد عضو بقيمة (كـ C). التعداد يُخزَّن بقيمة عضوه: `عدد64(ل)` القيمة، و`لون(ن)` بالقيمة، و`لكل` بترتيب التعريف، وهو حقل في `هيكل_سي` (الملفات الثنائية وC).

```ميم
تعداد حالة: طبيعي16
    تم = 200
    غير_موجود = 404
    خطأ_الخادم = 500
تعداد اتجاه: عدد8
    يسار = -1
    وسط
    يمين
ح = حالة.غير_موجود
اطبع(ح, " ", عدد64(ح), " ", حجم_النوع(حالة), " ", حالة(500) والا حالة.تم)
لكل ا في اتجاه:
    اطبع(ا, " = ", عدد64(ا))
```

```الناتج
غير_موجود 404 2 خطأ_الخادم
يسار = -1
وسط = 0
يمين = 1
```


```ميم
تعداد لون: طبيعي8
    احمر = 300
```

```خطأ
رمز الخروج: 2
--- stdout ---
--- stderr ---

[خطأ دلالي E0481] سطر 2:5 - قيمة العضو 'احمر' (300) خارج مدى 'طبيعي8' (من 0 إلى 255)
   2 |     احمر = 300
     |     ^~~~
  تلميح: وسّع عرض التعداد (تعداد الاسم: عدد64) أو صغّر القيمة.
```


**الاتحاد الموسوم** (منذ 0.15.0). إن أضفت حقولاً بعد اسم العضو `عضو(اسم نوع, ...)` صار التعداد «موسوماً»: كل عضو يحمل بيانات مختلفة. البناء `تعداد.عضو(قيمة, ...)` والفك `حاله تعداد.عضو(رابط, ...):`. الوسم i64 دائماً (عرض التعداد الموسوم لا يُحدَّد). العضو بلا حقول يُكتب في `حاله` بلا أقواس. التعداد الموسوم لا يُشير إلى نفسه بالقيمة (استخدم `مؤشر[...]`).

```ميم
تعداد شكل:
    دائرة(نق كسر64)
    مستطيل(ع كسر64, ط كسر64)
    نقطة_فقط

داله مساحة(ش شكل) كسر64:
    حالات ش:
        حاله شكل.دائرة(نق):
            ارجع 3.14159 * نق * نق
        حاله شكل.مستطيل(ع, ط):
            ارجع ع * ط
        حاله شكل.نقطة_فقط:
            ارجع 0.0
    ارجع 0.0

اطبع(مساحة(شكل.دائرة(1.0)))
اطبع(مساحة(شكل.مستطيل(3.0, 4.0)))
اطبع(مساحة(شكل.نقطة_فقط))
```

```الناتج
3.14159
12.0
0.0
```

الربط `_` يتجاهل الحقل دون إعلان متغير:

```ميم
تعداد نتيجة:
    نجح(قيمة عدد64)
    فشل(سبب نص, كود عدد64)

داله طباعة(ن نتيجة) فراغ:
    حالات ن:
        حاله نتيجة.نجح(ق):
            اطبع("نجح:", ق)
        حاله نتيجة.فشل(_, كود):
            اطبع("فشل:", كود)

طباعة(نتيجة.نجح(42))
طباعة(نتيجة.فشل("خطأ", 404))
```

```الناتج
نجح:42
فشل:404
```

**القيود المعروفة.** لا ترتيب (`<`) بين الأعضاء بلا `يحقق قابل_للمقارنة`. و`==` بين قيمتين موسومتين تلزمها
`يحقق قابل_للمساواة` في تعريف التعداد (منذ 0.17.0، [14-generics.md](14-generics.md))؛ **وبلا إعلانها خطأ ترجمة**
(`E0536` منذ 0.17.3) يذكر السمة — وكان يُقبل ويرجع `خطاء` دائماً حتى 0.17.2. الأخطاء
ليست تعداداً: مجموعتها مفتوحة عامة ([13-errors.md](13-errors.md)).

**أخطاء محتملة.**

```ميم
تعداد اشارة:
    احمر
    اخضر
ا = اشارة.احمر
حالات ا:
    حاله اشارة.احمر:
        اطبع("قف")
```

```خطأ
رمز الخروج: 2
--- stdout ---
--- stderr ---

[خطأ دلالي E0388] سطر 5:1 - 'حالات' على التعداد 'اشارة' لا تذكر: اخضر
   5 | حالات ا:
     | ^~~~~
  تلميح: اذكر كل عضو في 'حاله'، أو أضف  حاله _:  لما بقي.
```
