**يعمل ميم على لينكس x86_64 الآن.** ويندوز وماك غير متاحين في 1.0.

:::caution[أين يعمل]
- **حزمة المجمّع** تحتاج glibc 2.35 أو أحدث (glibc مكتبة C الأساسية في لينكس). جُرّبت على أوبونتو 22.04 ودبيان 12.
- **الملف الذي تبنيه** ساكن، فلا يحتاج مكتبات على الجهاز الذي يشغّله. تقول وثائق المجمّع (`docs/build.md`)، ولم يجرّب هذا الموقع ذلك: «جُرّب على دبيان 12 وأوبونتو 22.04 وألباين 3.20 (x86-64)، وفي حاوية ليس فيها ملف واحد غيره».
:::


## 1. احصل على المجمّع

نزّل أرشيف المجمّع من صفحة [التنزيل](/download/)، وتحقق من بصمته هناك، ثم فكّه:

```sh
tar -xJf meem-0.9.0-linux-x86_64.tar.xz
export PATH="$PWD/meem-0.9.0-linux-x86_64:$PATH"
```

في المجلد المجمّع وكل ما يلزمه، فلا يحتاج بايثون ولا تثبيتاً. السطر الثاني يجعل الأمر `meem` متاحاً في هذه الطرفية. ولتجعله متاحاً في كل طرفية، أضف السطر إلى ملف إعداد الصدفة (مثل `~/.bashrc`) بالمسار الكامل للمجلد.

## 2. تحقق من التثبيت

```sh
meem --version
meem --self-test
```

يطبع الأمر الثاني سطراً واحداً يقول إن الفحص الذاتي نجح، أو يذكر سبب الفشل.

## 3. شغّل أول برنامج

اكتب في ملف اسمه `مرحبا.م`:

```ميم
اطبع("مرحبا يا عالم")
```

ثم:

```sh
meem مرحبا.م
```

## 4. ابنِ ملفاً يعمل وحده

```sh
meem build مرحبا.م -o مرحبا
./مرحبا
```

الناتج ملف تنفيذي مستقل لا يحتاج ميم ولا بايثون. التفاصيل في صفحة [البناء](/docs/build/).
