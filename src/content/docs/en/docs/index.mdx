## Goal

The complete reference for the Meem language. Its only source is the **reference handbook** in the compiler repository (`docs/handbook/`, commit <code dir="ltr">{hb.source.commit.slice(0, 7)}</code>). To learn from scratch, start with [Learn Meem](/en/learn/).

The handbook is written in Arabic. The pages generated from it are shown in Arabic on this English site, with a notice, until they are translated; the pages written for the site itself (understanding Meem, coming from another language, the quick references) are in English.

## Releases

The handbook describes release 0.17.3: sized numbers, the optional type, tuples, enums with a payload, generics and traits, the `مجموعات` (collections) library, line-by-line reading and writing, the confirmed leak `E0472` as a compile error, and the new warning policy. Everything added is marked with its release («منذ 0.12.0», since 0.12.0, for example), and what is not implemented yet is marked «مخطط» (planned). The current download on this site is 0.17.3, and what changed after 0.10.0, release by release, is in [the migration pages](/en/docs/migration/to-0-17/).
