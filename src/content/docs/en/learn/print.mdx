## Goal

To print text and numbers, and to know that `اطبع` (print) accepts more than one value.

## Explanation

- A **program** is a text file with the extension `.م` that holds instructions. The **compiler** `meem` reads it and runs it ([glossary](/en/docs/glossary/)).
- `اطبع(...)` writes what is between the parentheses to the screen, then moves to a new line.
- A **string** is text between double quotes: `"مرحبا"`.
- `اطبع` accepts several values separated by commas, and prints them next to each other with no space. If you want a space between the values, write it yourself inside the string.

## Common mistakes

Two common mistakes: a string without quotes, and `+` between a string and a number. The `+` sign joins a string to a string only; a string with a number is an error the compiler catches before the program runs:
