**مولَّدة** من `meem --list-options --json` (العقد 1)؛ الشرح في
`cli.md` <small>(وثيقة في مستودع المجمّع)</small> و`tools-contract.md` <small>(وثيقة في مستودع المجمّع)</small>.

| الخيار | القيمة | النطاق | منذ | الوصف |
|---|---|---|---|---|
| `--check` | — | tool | — | فحص الملف دون تنفيذه |
| `--fix` | — | tool | — | كتابة نسخة بالصيغ الجديدة (ملف_مصحح.م) بجوار الأصل |
| `--json` | — | any | — | خرج منظّم JSON للأمر المرافق |
| `--stdin` | — | check | — | قراءة الشيفرة من الإدخال القياسي؛ الملف المذكور يحدد الاسم ومجلد الاستيراد |
| `--overlay` | مسار=ملف | check | — | محتوى الملف المستورَد «مسار» يُقرأ من «ملف» (نسخة لم تُحفظ بعد) |
| `--strict` | — | run | — | كل تحذير خطأ يمنع التنفيذ (عدا التحذيرات الاستشارية) |
| `--deny-deprecated` | — | run | 0.4.0 | تحذيرات الصيغ المهجورة وحدها تصير أخطاء |
| `--debug-mem` | — | run | — | كشف أخطاء الذاكرة وقت التشغيل وتقرير بما لم يُحرَّر |
| `--wrap-overflow` | — | run | — | التفاف ناتج + و - و * عند تجاوز 64 بت بدل خطأ التشغيل |
| `--check-overflow` | — | run | — | مقبول للتوافق ولا أثر له (كشف التجاوز مفعّل افتراضياً) |
| `--no-ffi` | — | run | — | رفض أي تصريح «خارجي» خارج المكتبة القياسية |
| `--no-default-allocator` | — | run | 0.7.0 | وضع بلا_افتراضي للبرنامج كله عدا المكتبة القياسية: كل حجز يذكر مخصصه |
| `--no-system` | — | run | 0.7.0 | رفض استيراد وحدتي ملفات ونظام في برنامج المستخدم (لا ملفات ولا بيئة ولا وسائط)، للملعب |
| `--no-unsafe` | — | run | 0.7.0 | رفض المنطقة «خطر» (الطبقة المنخفضة) خارج المكتبة القياسية، للملعب |
| `--emit-ir` | ملف | run | — | حفظ شيفرة LLVM IR في الملف المذكور، أو بجوار المصدر بامتداد .ll |
| `--full-buffered` | — | run | — | عدم تفريغ المخرجات عند كل سطر حين تُوجَّه إلى ملف أو أنبوب |
| `--debug` | — | run | — | عرض التفاصيل الكاملة عند خطأ داخلي في المجمّع |
| `--` | وسائط... | run | 0.5.1 | ما بعده وسائط للبرنامج نفسه (نظام.وسائط)، لا خيارات للمجمّع |
| `-o` | ناتج | build | 0.5.0 | اسم الملف الناتج |
| `-O` | — | build | 0.5.2 | مقبول للتوافق ولا أثر له: البناء محسَّن افتراضياً (O2) منذ 0.6.0 |
| `-O0` | — | build | 0.6.0 | بناء بلا تحسين O2: أسرع بناءً وأبطأ تنفيذاً (تحسين التشغيل المباشر الخفيف نفسه) |
| `--cpu=native` | — | build | 0.6.0 | تعليمات معالج هذا الجهاز: أسرع، وقد لا يعمل الملف على معالج أقدم (للبناء المحلي) |
| `--static` | — | build | 0.5.0 | ربط ساكن: ملف بلا اعتماد |
| `--dynamic` | — | build | 0.5.0 | ربط حركي بمكتبة C للنظام |
| `--emit-obj` | — | build | 0.5.0 | التوقف عند الملف الكائني بلا ربط |
| `--target` | هدف | build | 0.5.0 | بناء لهدف آخر (x86_64-linux-musl، x86_64-linux-gnu) |
| `--link-arg` | وسيط | build | 0.5.0 | وسيط إضافي للرابط |
| `--version` | — | tool | — | رقم الإصدار |
| `--help` | — | tool | — | المساعدة |
| `--self-test` | — | tool | 0.4.0 | فحص ذاتي سريع للتثبيت |
| `--list-keywords` | — | tool | — | كلمات اللغة وأنواعها وثوابتها ودوالها المدمجة ومعاملاتها |
| `--list-types` | — | tool | — | الأنواع وصيغها وأنواع تواقيع الدوال الخارجية |
| `--list-deprecated` | — | tool | 0.4.0 | الصيغ القديمة المقبولة بتحذير وبديل كلٍّ منها |
| `--list-modules` | — | tool | — | الوحدات التي يجدها «استورد» من مجلد الملف أو المجلد الحالي |
| `--list-module` | — | tool | — | واجهة وحدة: دوالها وهياكلها وثوابتها بتواقيعها وتعليقات شرحها (الاسم أو المسار وسيط موضعي) |
| `--list-options` | — | tool | 0.5.2 | خيارات سطر الأوامر هذه، بما يأخذه كلٌّ منها ومتى أُضيف |
