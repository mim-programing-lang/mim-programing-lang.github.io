## Goal

To split a string, search it, and trim the spaces from both ends.

## Explanation

- `تقسيم(ن, فاصل)` (split) splits the string into a list of strings at every place the separator appears.
- `قص_الفراغات(ن)` (trim) returns the string without spaces at its start and end.
- `يحوي(ن, جزء)` (contains) answers: does the part appear in the string? And `يبدأ_بـ(ن, بادئة)` (starts with) answers: does the string start with it?

<aside class="lesson-note">

**Note:** `جزء` (slice) and `قص_الفراغات` return a «view» onto the original string without copying, and `طول`, comparison and indexing on a view allocate nothing (since 0.10.0). But a view lives as long as its original string: do not free the original while you still use the view. `تقسيم`, on the other hand, allocates the list and a string for each piece. Details in [allocation and performance of builtins](/en/docs/stdlib/allocation/).

</aside>

## Common mistakes

Thinking that `طول` (length) counts bytes: it counts code points, and diacritics count too. A **code point** is the counting unit for strings ([glossary](/en/docs/glossary/)).
