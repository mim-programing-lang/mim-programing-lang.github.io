المصطلح كما يُكتب في الكتاب والرسائل، ومقابله بالإنجليزية، ومعناه في ميم. الكلمات المفتاحية والأنواع بأسمائها في
[المفردات](/docs/language/lexicon/).

| المصطلح | English | المعنى في ميم |
|---|---|---|
| المجمّع | compiler | `meem`: يترجم البرنامج وينفّذه (`meem ب.م`) أو يبنيه ملفاً تنفيذياً (`meem build`) |
| التشغيل المباشر | direct run | ترجمة في الذاكرة وتنفيذ فوري |
| البناء | build | ملف تنفيذي مستقل |
| خطأ ترجمة | compile error | يُكتشف قبل التنفيذ؛ رمز الخروج 2 |
| خطأ تشغيل | runtime error | أثناء التنفيذ؛ رمز الخروج 3 |
| تحذير | warning | لا يمنع التنفيذ؛ يصير خطأً مع `--strict` |
| تحذير استشاري | advisory warning | يبقى تحذيراً مع `--strict` |
| صيغة مهجورة | deprecated form | مقبولة بتحذير، وستصير خطأً |
| المحلل اللفظي / النحوي / الدلالي | lexer / parser / semantic analyzer | مراحل الترجمة، بأسمائها في الرسائل |
| التشخيص | diagnostic | خطأ أو تحذير بموضعه، ومنه خرج `--check --json` |
| عقد الأدوات | tools contract | ما يعد به خرج JSON ورموز الخروج للمحرر والأدوات |
| وحدة | module | ملف `.م` يُستورد |
| المكتبة القياسية | standard library | الوحدات التي تأتي مع المجمّع |
| مدمجة | builtin | دالة يعرفها المجمّع بلا استيراد |
| مخصص | allocator | ما تُحجز منه الذاكرة وتُعاد إليه |
| المخصص الافتراضي | default allocator | ما يُحجز منه حين لا يُذكر مخصص |
| ساحة | arena | مخصص يعيد كل ما حُجز منه دفعة بـ`اعد` |
| كاشف | debug allocator | مخصص يبلّغ عن التسريب وسوء الاستعمال |
| تسريب | leak | ذاكرة لم تُحرَّر قبل الخروج |
| تحرير | free | إعادة ذاكرة إلى مخصصها |
| خاتمة | defer | جملة مؤجلة إلى الخروج من الكتلة (`خاتمه`) |
| المنطقة الخطرة | unsafe block | `خطر:`: عمليات الذاكرة الخام |
| شريحة | slice | مؤشر وطول، بالقيمة، لا تملك |
| مؤشر | pointer | عنوان خانة أو كتلة |
| مؤشر خام | raw pointer | `void *` من C |
| نوع بحجم ثابت | fixed-size type | `عدد32`، `بايت`...: نوع تخزين |
| عرض (نص) | view | نص على بايتات نص آخر بلا نسخ (`جزء`، `قص_الفراغات`) |
| نقطة ترميز | code point | وحدة العدّ في النصوص |
| استدعاء خارجي | FFI | استدعاء دالة C بـ`خارجي` |
| استدعاء عكسي | callback | دالة ميم تستدعيها C |
| مؤشر دالة | function pointer | قيمة من نوع `داله(...) نوع` |
| هيكل بتخطيط C | C struct | `هيكل_سي` |
| نسخة الدالة | function instance | نسخة دالة عامة لأنواع وسائط معينة |
| LLVM | LLVM | مكتبة ترجمة يولّد بها المجمّع كود الآلة من البرنامج (الخيار `--emit-ir` يحفظ ما يعطيه لها) |
| IEEE-754 | IEEE-754 | معيار تمثيل الأعداد الكسرية في الحاسوب؛ `كسر` في ميم عشري مضاعف الدقة عليه (64 بتاً) |
| الملعب | playground | تشغيل برنامج صغير على الموقع (`playground.md` <small>(وثيقة في مستودع المجمّع)</small>) |
