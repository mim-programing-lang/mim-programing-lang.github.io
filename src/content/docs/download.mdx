## المتطلبات

- **لينكس x86_64.** ويندوز وماك غير متاحين بعد.
- **glibc 2.35 أو أحدث** (glibc مكتبة C الأساسية في لينكس): أوبونتو 22.04 ودبيان 12 وما بعدهما. لا تعمل الحزم على أقدم منها (أوبونتو 20.04، دبيان 11).
- **المجمّع** لا يحتاج بايثون ولا مجمّع C ولا رابطاً. وفك الأرشيف يحتاج `xz-utils`، وهي مثبّتة عادة في أنظمة سطح المكتب، وإلا فثبّتها: `sudo apt install xz-utils`.
- **المحرر بصيغة deb** (حزمة أوبونتو ودبيان) يعتمد على `libwebkit2gtk-4.1-0` و`libgtk-3-0` من مستودعات التوزيعة، ويثبّتهما `apt` معه.
- **المحرر بصيغة AppImage** (ملف واحد يُشغَّل دون تثبيت) يحتاج `libfuse2`، أو التشغيل بالخيار `--appimage-extract-and-run`.
- **الملف الذي يبنيه المجمّع** ساكن لا يطلب شيئاً على الجهاز الذي يشغّله.

## التثبيت والتشغيل

### المجمّع

فك الأرشيف في أي مجلد، ثم شغّل `meem` من داخله. لا يحتاج تثبيتاً ولا صلاحيات مدير:

```sh
tar -xJf meem-0.9.0-linux-x86_64.tar.xz
meem-0.9.0-linux-x86_64/meem --version
meem-0.9.0-linux-x86_64/meem برنامج.م
```

يُنقل المجلد كما هو، ولا يُكتب فيه شيء عند التشغيل. الخطوة التالية: [البدء](/start/).

### محرر ميم (deb)

لأوبونتو ودبيان:

```sh
sudo apt install ./meem-editor_0.3.0_amd64.deb
```

ثم افتح «محرر ميم» من قائمة التطبيقات، أو شغّله بالأمر `meem-editor`.

### محرر ميم (AppImage)

لأي توزيعة فيها glibc 2.35 أو أحدث ومكتبات الواجهة:

```sh
chmod +x meem-editor_0.3.0_amd64.AppImage
./meem-editor_0.3.0_amd64.AppImage
```

إن ظهرت الرسالة «Cannot mount AppImage» فثبّت `libfuse2`، أو شغّله بـ `./meem-editor_0.3.0_amd64.AppImage --appimage-extract-and-run`.
