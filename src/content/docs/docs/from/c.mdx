ميم تُترجم مثل C إلى شيفرة آلة (عبر LLVM)، وذاكرتها يدوية. لكنها تفحص الحساب والفهرسة دائماً، وتكتب الأخطاء قيماً في التوقيع.

## ما يقابل ماذا

| في C | في ميم |
|---|---|
| `int8_t` .. `int64_t`، `uint8_t` .. `uint64_t`، `float`، `double`، `bool` | `عدد8` .. `عدد64`، `طبيعي8` .. `طبيعي64`، `كسر32`، `كسر64`، `منطقي`؛ والتوسيع ضمني والتضييق صريح يُفحص (`عدد8(ن)`) |
| `char *` منتهٍ بصفر | `نص`: UTF-8 بطوله، و`طول` يعدّ **الأحرف** لا البايتات |
| `struct` | `هيكل`: يُمرَّر بالقيمة؛ وإرجاع عدة قيم بصف: `(خارج عدد64, باقي عدد64)` |
| `union` مع وسم | `تعداد` بحمولة: `دائرة(نق كسر64)`، وفكّه بـ `حالات` (منذ 0.15.0) |
| مصفوفة ثابتة / مصفوفة تنمو | `مصفوفة[نوع, حجم]` (تُنسخ عند الإسناد) / `قائمة[نوع]` |
| `malloc` / `free` | الحجز من مخصص (ضمني في الغالب) / `حرر(س)` |
| `T *` و`NULL` | `مؤشر[نوع]` بـ `جديد` و`محتوى`، و`لاشيء`؛ **لا حساب عناوين** |
| `void *` من مكتبة | `مؤشر_خام`، ولا يُقرأ إلا داخل `خطر` |
| رمز إرجاع و`errno` | `!نوع` و`خطأ.اسم`، ومعالجته إلزامية |
| `goto cleanup` | `خاتمه` و`خاتمه_عند_خطأ` |
| `#include` | `استورد` |
| `printf` | `اطبع` بالفواصل، و`رياضيات.نسق` و`نسق_عدد` للتنسيق |
| تجاوز غير معرَّف | خطأ تشغيل برمز 3؛ والالتفاف صريح: `جمع_ملتف` وأخواتها لعملية، و`--fast` للبرنامج كله |
| استدعاء مكتبة C | `خارجي` بأنواع C صريحة |

## ما سيفاجئك (من تجربة كتابة برامج حقيقية بـ 0.9.1، ومُراجَع على 0.17.1)

- **وضعان كما في Zig:** `meem برنامج.م` يشغّله بكاشف ذاكرة يكشف الاستعمال بعد التحرير والتحرير المزدوج بسطريهما، و`meem build` يبني بلا كاشف، وفيه الاستعمال بعد التحرير عبر اسم آخر سلوك غير معرَّف كما في C. ابنِ بـ `--debug` لتبقي الكاشف.
- **`حرر` لا يتبع:** تحرير قائمة قوائم يترك الداخلية، كـ `free` على مصفوفة مؤشرات.
- **الأحرف قبل البايتات:** `طول` و`جزء` بالأحرف؛ والعمليات بالبايت بأسماء صريحة (`طول_بايت`، `جزء_بايت`، `بايتات_نص`، منذ 0.14.0).
- **المعمّم بالنسخ:** `داله اكبر[ن](...)` و`هيكل زوج[ا, ب]:` يُنسخان لكل تركيبة أنواع، والقيد سمة (`[ن يحقق قابل_للمقارنة]`، منذ 0.17.0)؛ ولا تعدد أشكال حركي.
- **`هيكل_سي` يُعرَّف قبل التصريح الذي يستعمله.**
- **الخطأ قيمة بسياق صغير** (منذ 0.11.0): اسم ورسالة وسبب، و«نشأ في» بسطر أول `ارجع` أرجعه؛ لا تتبّع كامل للمكدس.
- **لا `printf` ولا دوال بعدد متغير من الوسائط**، ولا هياكل بالقيمة إلى C.
- **البناء الساكن (musl) أبطأ** من `--dynamic` في البرامج الكثيرة الحجز.

## وما سيعجبك

- الحدود والتجاوز مفحوصة افتراضياً، برسالة بالسطر والمعرّف.
- `خاتمه` و`خاتمه_عند_خطأ` بترتيب صحيح عبر الدوال.
- ملف تنفيذي ساكن بعشرات الكيلوبايتات، يُبنى في نحو ثانية.
- أداء الشيفرة الخوارزمية بمستوى C ([دايكسترا وشجرة بحث](/learn/projects/algorithms/)).
- `خارجي` سطر لكل دالة، والرمز يُفحص عند الترجمة.
