## Goal

To store a value under a name and calculate with it, and to tell integer division from fractional division.

## Explanation

- A **variable** is a name you give to a value: `الطول = 7`.
- Every value has a **type**: `عدد` (integer) for whole numbers, `كسر` (float) for numbers with a decimal point (such as `3.5`), and `نص` (string) for text.
- A variable's type is set by the first value you give it, or you write it after the name: `س عدد = 3`.
- Division `/` between two integers gives an integer: it drops what comes after the decimal point (rounding toward zero). If either side is a float, the result is a float: `7 / 2.0` gives `3.5`.
