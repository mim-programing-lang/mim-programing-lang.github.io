ستجد في ميم أشياء مألوفة: الكتل بالمسافة البادئة بعد `:`، و`لكل ... في`، والقوائم والقواميس بترتيب الإدراج. والفروق الكبيرة: الأنواع ثابتة تُفحص قبل التشغيل، والبرنامج يُترجم إلى ملف تنفيذي، والأخطاء قيم لا استثناءات، والذاكرة يدوية.

## ما يقابل ماذا

| في بايثون | في ميم |
|---|---|
| `if` / `elif` / `else` | `اذا` / `غير ذلك اذا` / `غير ذلك` |
| `for x in range(1, 11):` | `لكل س في مدى(1, 11):` |
| `while` و`break` و`continue` | `طالما` و`توقف` و`تجاوز` |
| `def f(x: int) -> int:` | `داله ف(س عدد) عدد:` (الأنواع إلزامية) |
| `list` و`dict` | `قائمة[نوع]` (نوع واحد) و`قاموس[مفتاح, قيمة]` |
| `class` بحقول | `هيكل` بحقول، والدوال تأخذه معاملاً (لا طرائق) |
| `import math` ثم `math.sqrt` | `استورد رياضيات` ثم `رياضيات.جذر` |
| `print(a, b)` | `اطبع(ا, ب)`: **بلا مسافة** بين القيم؛ اكتبها أنت |
| `try` / `except` | `!نوع` و`جرّب` و`والا` |
| `None` | `لاشيء` (للنص والمؤشر) |
